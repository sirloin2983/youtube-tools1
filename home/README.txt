==========================================================
  ホーム(ランチャー)  v0.15.0  はじめに読んでください
==========================================================

ツール(切り抜きスタジオ・編集・cut2resolve)を、1回の操作でまとめて起動・終了するためのホームです(以前の呼び名は「入口」。
v0.11.0 の画面の全面見直しで「ホーム」に変えました。中身の役割は同じです)。
v0.10.0(2026-09-26)から、文字起こしツールは「編集」(文字起こし・カット・パック)になり、cut2resolve の画面は「編集」に統合しました
(cut2resolve はパックを作る部品として裏で動き、ホームのカードは出しません)。
統合計画(docs/design/integration-plan.md)の段階1で作り、段階3から「ツールをホームの中に取り込む」ことを始めました。
3つとも取り込みます: 切り抜きスタジオ(http://localhost:8700/studio/)・文字起こし(/transcribe/)・cut2resolve(/cut2resolve/)。
文字起こしの認識(faster-whisper)だけは、落ちてもホームごと止まらないよう、別のプログラム(editor\tx_worker.py)で動きます。
各ツールの start.bat での単独起動は 2026-09-26 にやめました(起動は start.bat だけ)。使い方の全体はリポジトリ直下の README.txt。

■ 使い方
  1. youtube-tools フォルダ(リポジトリ直下)の start.bat をダブルクリック(Mac は start.command)
  2. 黒い画面が1つ開き、ツールが裏で起動します。ブラウザでホームの画面(http://localhost:8700/)が開きます
  3. ホームの上には「次にやること」(校正待ち・パック待ち・進行中の処理。最大5件)が出ます。押すとその作業の画面へ直接入れます。
     下には案件(配信ごと)の一覧があり、使うツール(スタジオ・編集)を「編集で開く」などのリンクや、ヘッダー左の「スタジオ」「編集」
     の切り替えで開けます(同じタブの中で行き来します)
  4. 終わるときは、下の「詳しく」を開いて「すべて終了」(誤操作を防ぐため2回押し)を押すか、黒い画面を閉じる / Ctrl+C

  ※ 黒い画面は1つだけです。3つのツールの出力は黒い画面ではなくログ(下の「詳しく」の「ログ」)に出ます
  ※ ツールの画面を閉じても、サーバーは動いたままです。案件の一覧の「編集で開く」やヘッダーの切り替えでいつでも開き直せます

■ 友人からの依頼の受付(v0.15.0。設計は docs/design/friend-intake.md)
  友人が Dropbox に送った依頼(配信の URL・友人が切り抜いた動画)を、ホームが見張って文字起こしまで自動で流します。
  1. 友人に送ってもらう仕組みを用意する: 友人用のプログラム(request-sender\README.txt)か、Dropbox のファイルリクエストのリンク
  2. ホームの「依頼の受付」を開き、見張るフォルダ(Dropbox\アプリ\切り抜き依頼 など)を入れてオンにする。
     Dropbox のアプリでそのフォルダを「オフラインで利用可能」にしておく(「オンラインのみ」だと PC にファイルが来ません)
  3. 届いたら 30 秒ごとの確認で受け付けます(「今すぐ確認」ですぐ)。進み具合は「まとめて実行」と同じ所に出ます
     - 配信の URL: 解析 → 点数の高い N 個を採用 → 書き出し → 文字起こし(パックはしません)。N は依頼ごと(1〜10。書かなければ設定の既定)
     - 動画: 作業データ(%LOCALAPPDATA%\youtube-tools\app\intake\日付\)へコピーしてから文字起こし。配信者を指定されていれば、パックのときの字幕の色に使います
     - 受け付けた元のファイルは 受付済み\日付\ へ、断ったものは 失敗\ へ移し、理由を「<名前>.理由.txt」に書きます(消しません)
  手で送るときの形(ファイルリクエストなど):
     - 動画(.mp4 .mov .mkv .webm .m4v): ファイル名の頭に【さくらみこ】のように書くと配信者として読みます
     - .txt: 1行に「URL [数]」(例: https://youtu.be/xxxxxxxxxxx 5)。空の行・# で始まる行は無視。.url(ショートカット)も受け付けます
  安全のため: URL は YouTube だけ・動画は ffprobe で確かめてから・同じ配信 / 同じ動画は2回流さない・1日の上限(超えた分は明日に回す)・
  配信の長さ / 動画の大きさの上限(設定で変えられます)。配信中・配信前の URL は断ります。
  ホームが起動していない間に届いた依頼は、次に起動したときに流します。覚えている内容は …\app\intake-state.json

■ ホームの画面でできること
  - 「次にやること」: 校正待ち・パック待ち(「編集」の文書の一覧から。校正・パックのタブへ直接リンク)・進行中の処理(まとめて実行)
  - 案件(配信ごと)の一覧: 配信1本ごとに、書き出した切り抜き・文字起こし(校正の進み具合)・パックの有無・「まとめて実行」・状態・メモ。
    どの配信にも紐づかない文字起こし(手元の動画ファイルなど)は「単体の文字起こし」のまとまりに入り、検索して選ぶと
    まとめて文字起こし・パックを進められます(以前の「編集」の履歴の「選んで、まとめて実行」と同じ)
  - まとめて実行の結果はファイルに残ります(%LOCALAPPDATA%\youtube-tools\app\logs\autorun-runs.jsonl。1MB を超えたら .1 に回します)。
    ホームを起動し直しても、案件・単体の文字起こしの行に「前回 …: 失敗 ・ 止まった理由(3日前)」が出て、
    案件の下の「まとめて実行の記録」(既定で閉じています)を開くと、終わった実行を新しい順に見られます。
    書くのは実行が終わったとき(完了・失敗・中止・「すべて終了」で順番待ちを消したとき)だけなので、黒い画面を閉じるなどで
    ホームが強制終了されたときに実行中だった分は残りません(もう一度押せば続きから進みます)
  - 「詳しく」(既定で閉じています): 各ツールの状態(起動中・動作中・別の画面で起動済み・停止・異常終了)・開く/起動/停止/再起動・
    ログ・作業データの置き場所・窓で開く(既定でオン)・すべて終了
  - ⚙ の設定(右上): テーマ(明るい/暗い/OSに合わせる)・文字の大きさ・キーの帯を出すか(全体の設定。どのツールで変えても全部に効きます)

■ ホームに取り込んだツール
  ホームのプログラムの中で動くので、カードに「ホームに取り込み」と出て、「停止」「再起動」は押せません(「すべて終了」で一緒に終わります)。
  アクセスの記録は …\app\logs\studio.log・cut2resolve.log に、ツール自身の記録は %LOCALAPPDATA%\youtube-tools\studio\studio.log・…\cut2resolve\work\serve.log に出ます。
  「すべて終了」のとき cut2resolve の書き出しが動いていれば、取り消してから終わります。
  取り込みで問題が出たときは、start.bat の代わりに黒い画面で「python home\launch.py --no-mount」と打つと、以前と同じく別のプログラムとして起動します。
  安全のため、ホームと取り込んだツールの画面には、外から入れられたスクリプトを動かさない仕組み(CSP)と、書き込みの操作の合言葉(起動ごとに変わる)を付けています。
  画面を開いたままホームを起動し直したときに「合言葉が違います」と出たら、画面を再読み込みしてください。

■ すでに別の黒い画面でツールを起動している場合
  そのツールは「別の画面で起動済み」と表示され、ホームからは起動も停止もしません(同じデータを2つのサーバーで取り合わないため)。
  ホームでまとめて管理したいときは、その黒い画面を閉じてから、「詳しく」の「起動」を押してください。
  古い版が動いているときは、カードにその旨が出ます。

■ 異常終了したとき
  カードに「異常終了」と出て、黒い画面にもログの最後の数行が出ます。「ログ」を開いて最後のメッセージを確認し、「起動」で起動し直せます。
  自動では起動し直しません(同じ原因で何度も落ち続けるのを避けるため)。

■ ファイル
  start.bat / start.command   起動用(リポジトリ直下)
  home\launch.py                        ホームのサーバー(3つのツールの起動・監視・停止と、ホームの画面。/cases.html は #cases へ 302)
  home\portal.html / portal.js / portal.css   ホームの画面(次にやること・案件の一覧・単体の文字起こし・「詳しく」。見た目は ui-kit\ をそのまま使う)
  app\logs\                            以前のログ(v0.5.0 から %LOCALAPPDATA%\youtube-tools\app\logs。消してよい)
  home\tests\test_launch.py / e2e_portal.py   テスト
  .runtime\portal.json                 ホームのポート(各ツールの .runtime と同じ置き場。各ツールの動きには影響しない)

■ コマンド(上級者向け)
  python home\launch.py [--no-open] [--port 8700] [--only studio,transcribe]
    --no-open   ブラウザを開かない
    --port      ホームのポート(使用中なら次の番号。8700〜8719)
    --only      起動するツールを絞る(studio / transcribe / cut2resolve をカンマ区切り)
    --no-mount  ツールをホームに取り込まず、別のプログラムとして起動する(以前の動き。問題が出たときの戻し方)

  各ツールは、それぞれのフォルダで「serve.py <既定のポート> --no-open」として起動します(ホームと同じ Python)。
  Mac / Linux の文字起こしツールは、editor/.venv があればその Python を使います。

■ 安全のための決まり
  - ホームのサーバーは 127.0.0.1(この PC)だけで待ち受けます。他の PC からは開けません
  - 起動・停止などの操作は、ホームの画面からだけ受け付けます(他のサイトからの操作・埋め込みを拒否)
  - ログには動画の題名やファイルの場所が入ることがあります。この PC の画面にだけ表示し、外には送りません
