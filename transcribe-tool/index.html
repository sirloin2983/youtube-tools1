認識精度の測定

行の「校正済み」(聞いて確認して、文字が正しいと判断した印。Shift+Space)を正解として、機械の出力との文字誤り率(CER)を出します。句読点・空白・記号・全角半角の違いは数えません。校正した行が増えるほど、数値が安定します。

評価用の基準の記録 施策(辞書・名簿・前処理・モデル・追加学習)を入れる前後で、評価用の成績を残して比べます。記録するのは「評価用のみ」の成績です。
設定の比較(A/B) 開いている文字起こしの「校正済み」の行の音声を、下の設定それぞれで認識し直し、正解との差を比べます(文字起こしは書き換えません)。モデルや「用語集」の有無で、どれが良いかを数字で選べます。重いモデルほど時間がかかります(処理状況に出ます)。
修正から学習した候補

直した文章と、元の認識結果の違いから「誤=>正」の候補を集めます。「登録」すると置換辞書に入り、次の文字起こしから自動で直ります。同じ間違いが何度も出るものから登録すると効果的です。1文字だけの修正は、前後の1文字を含めた形で候補に出ます。
登録しなくても、直した回数が多い間違いは、文字起こしの各行に「候補」として出ます(採用・却下できます。却下すると出にくくなります)。

修正データの書き出し(将来の追加学習・精度の測定用)
直した行ごとに「音声の範囲・機械の出力・直した文章」をまとめます(最大400行。音声は1行20秒まで)。話者の声や会話の内容が含まれるので、他人に渡すときは相手の同意を得てください。
保存データ(将来の学習用)

校正した成果を、元の動画に頼らずに使い回せる形で、このフォルダの dataset/ に自動で残します。校正済みの行(文章・話者・音の状態のメモ・機械の出力との対応)、人が消した行(幻覚などの「負例」)、行ごとの音声(16kHz・FLAC)が入ります。追加学習(LoRA)・声紋登録・別モデルでの再認識に、あとからそのまま使えます。

左のメニューの「保存済みの文字起こし」から選ぶか、新しく文字起こしを始めてください。
評価用の文字起こしです。辞書・提案・追加学習の元にはなりません。再認識はできません。一括置換と提案の採用は使えません(正解が機械で書き換わってしまうため)。
別の場所で先に更新されています。別のタブ・再認識・話者判別などで、保存済みの内容がこの画面の読み込み時と変わっています。自動保存は止めています。

話者・置換・書き出し
話者の自動判別
2人の対談なら「2人」を指定してください(「自動」だと、1人を複数に分けたり、逆にまとめたりしやすくなります)。「判別モデル」は声の特徴を見分ける部分です。日本語の音声でどれが合うかは、同じ範囲で切り替えて比べてください。すでに割り当てた話者は置き換わります。判別中は編集できません。
再認識(文字の間違いを、別のモデルで直す)
認識の失敗が多い行を、重いモデル(large-v3 など)で認識し直します。対象の行の音声だけを処理します(CPU では、行数に応じて時間がかかります)。BGM が大きい・声が重なった行は、直らないこともあります。対象の行の文字は上書きされます(直前の状態は、transcripts/.bak に1つだけ残ります)。判別中・再認識中は編集できません。
話者(名前の変更・手動での割り当て)
「▶ 聞く」で、その人の発言を順に再生できます(誰かを確かめて、名前を付けてください)。間違った行は、行の話者欄か、行の左端のチェックで複数行を選んで直せます。「要確認: 声が混ざっている可能性」は、1つの行に複数人の声が入っている行です(分割して直せます)。
履歴(自動バックアップ) 保存内容を、10分ごと、および再認識・話者判別の直前に自動で残します(1本あたり最新30世代)。間違えて直したり消したりしたときは、ここから戻せます(戻す前の状態も履歴に残ります)。まだ一度も編集していない文字起こしには、履歴はありません。

操作キー(左手だけで校正できます)

キー単体で操作します(Shift は不要)。例外は Space だけで、これは Shift+Space です(Space だけで押すと動画の再生・停止になるため)。文字を入力しているとき(入力欄にカーソルがあるとき)は使えません。Esc で入力欄から抜けてください。「校正」= 聞いて確認して「校正済み」の印を付ける作業です。

基本の流れ: S で行を選ぶ → 聞く(R) → 合っていれば Shift+Space / 直すなら T で入力 → Esc → Shift+Space。「移動したら自動で再生」(B)をオンにすると、Shift+Space の連打で「聞く → 確認 → 次を聞く」が続きます。聞き取れない・重なり・BGM は X / C / V でメモしておくと、あとで学習に使うかどうかを選べます。
