==========================================================
  切り抜きスタジオ  v0.1.7  はじめに読んでください
==========================================================

【これは何?】
  「配信ランキング」「自動切り抜き」「切り抜きマーカー」の3つを1つにまとめたツールです。
    ① 探す      ホロライブ・にじさんじ・ぶいすぽっ!・ネオポルテの人気配信を一覧にし、解析したい配信にチェック
    ② 解析      チェックした配信を順番に自動解析(音量・チャット・コメント欄)。終わったものから確認できます
    ③ 確認      自動で付いたマークをプレイヤーで見ながら直し、必要なものだけ mp4 に書き出します
    ④ コラボ    複数人のコラボ配信をグループにまとめ、一人が採用したマークを他の人の配信にも候補として転写します
  ※ 最初の版です。動作確認は作り物のテスト音声・チャット・疑似のYouTube応答までで、
    実際のYouTube(yt-dlp・埋め込みプレイヤー・ライブ配信)とWindowsでの実機は、まだ試していません。

【準備】
  1. Python 3(https://www.python.org/downloads/ 。Windows は「Add python.exe to PATH」にチェック)
  2. ffmpeg     Windows: winget install Gyan.FFmpeg   / Mac: brew install ffmpeg
  3. yt-dlp     Windows: winget install yt-dlp.yt-dlp / Mac: brew install yt-dlp
     (入れたら黒い画面を開き直してください。旧ツールで入れたものと共通です)
  4. start.bat をダブルクリック(Mac は start.command。初回だけ chmod +x start.command)
     ブラウザで http://localhost:8800/ が開きます。※ 127.0.0.1 ではなく localhost で開いてください(YouTube埋め込みのため)
  5. 画面上部の「設定」を開き、YouTube Data API のキーを入れる(ランキングの検索に必要。無くても②③は使えます)

【最初にやること(初回だけ)】
  ・設定 →「事務所の登録」で、4事務所のチャンネルを取り込みます。
    ホロライブ・にじさんじ・ぶいすぽっ! は「公式から取り込み」→「追加して解決」。
    ネオポルテは公式の一覧がないので、チャンネルのURL(または @ハンドル)を入れて「追加して解決」します。
  ・旧ツールの data.json や設定は引き継ぎません(新しく始まります)。

【使い方】
  ① 探す   期間・ワードを決めて検索 → 解析したい配信にチェック(最大10本)→「選んだ配信を解析に追加」
  ② 解析   順番に解析します。進み具合が見えます。失敗した配信は飛ばして続きます(「やり直し」で入れ直せます)。
           1本終わるごとに「確認する」が押せます(他の配信の解析は裏で続きます)。チャット取得が長いときは「チャットを待たずに進める」
  ③ 確認   自動マークが「候補」として入った状態で開きます。1件ずつ 採用 / 不採用 / 候補 を決めて、「採用」だけを書き出します。グラフに音量・チャットの山と、マークの点数・理由(「音量が急上昇」など)が出ます。
           ・マーク①〜⑤のボタン(長さ違いの区間)、I / O(IN・OUT)、±0.5 / 1 / 5秒の微調整、シアター、ライブ配信対応は切り抜きマーカーと同じです
           ・キー配置は「操作の設定」で変えられます(標準 / 左手だけ)
           ・判定: 各マークの「採用」「不採用」「候補」ボタン(書き出すと「書き出し済み」)。上の 全部/候補/採用/不採用/書き出し済み で絞り込み、時刻順/点数順で並べ替えられます
           ・キー(標準): ] 次のマーク / [ 前のマーク(移動するとその区間を自動再生)/ y 採用 / u 不採用(押すと次の候補へ進みます)。「操作の設定」で変更・自動再生や自動で次へ進む動作のオン/オフができます
           ・マークの行は ▾ で折りたたみ(「すべて折りたたむ」「すべて開く」もあります)。「候補をすべて採用」もあります
           ・書き出す対象: 採用のみ(標準)/ 採用+候補 / 不採用以外すべて。「全動画の採用を書き出す」で、採用マークがある全部の動画を順番に書き出します(この画面を開いたままにしてください)
           ・書き出しは切り抜きマーカーの方式: YouTube は必要な範囲だけ取得。精度優先/速度優先、画質の上限を選べます
           ・書き出し先: 標準ではこのフォルダの exports/<動画名>/。変更は設定の「出力先フォルダ」
           ・書き出し済みマークの時刻を動かす、または「採用」を押し直すと、「書き出し済み」が外れます(採用に戻り、書き出し直せます)
  入口は4つあります: ①ランキングから / ②URLを直接貼る / ③手元のファイル(フルパス)/ ④解析せずに確認画面だけ開く(手動でマークだけ付けたいとき)
  ④ コラボ   複数人のコラボ配信で、一人が付けたマークを他の人の配信の「同じ瞬間」にも候補として転写します(自動採用はしません。必ず候補として入り、採用/不採用は人が決めます)。
           1. ② の「解析する配信を入れる」で、まとめて入れた配信を「コラボとしてまとめる」にチェックすると、追加した動画が1つのグループになります(あとから ④ の画面でも、チェックボックスで選んで「まとめる」できます)。
           2. ④ の画面で、グループの各動画(基準の動画以外)に「アンカーを指定」→ 両方の動画で同じ瞬間を見つけて時刻を入力(1点だけでもよい。2点指定すると配信中のズレの変化(ドリフト)にも対応します)。
           3. これでズレの対応ができたので、以降はどちらかの配信でマークを「採用」にするたびに、同じグループの他の配信にも、その瞬間(前後2〜3秒広げた範囲)が「候補」として自動で追加されます。採用するかどうかは、その配信を見ながら人が決めてください。
           ・グループから動画を外しても、すでに転写された候補・採用済みマークは残ります。基準の動画を外す、または残り1本になる場合はグループごと削除されます(ズレの基準が失われるため)。

【解析のしかた】(自動切り抜き v0.2.0 と同じ)
  音声・チャット・コメント欄を、それぞれ「ふだん(前後5分の中央値)からどれだけ跳ね上がったか」で点数にして足し合わせます(重みは 音声1.0・チャット1.0・コメント0.7)。
  v0.1.4 の変更:
  ・チャットの遅れを動画ごとに自動推定します(音量の山とチャットの山の一致から。詳しい設定の「チャットの遅れを自動で推定する」。はっきりしないときは従来の「遅れ補正」の秒数を使います)。推定した秒数は解析結果の注意書きに出ます。
  ・配信の冒頭は、0秒で0倍 → 「冒頭の減点」の秒数(標準180秒)で1倍へ、なだらかに点数を戻します(挨拶・BGMの誤検出対策。0で無効)。
  ・コメント欄の時刻が1つのコメントに3つ以上ある場合(チャプター一覧)は、1つあたりの重みを 1/個数 に下げます。
  ・チャットの「！」1つだけでは盛り上がりに数えません(「！！」以上・「草」・「w」などは数えます)。
  v0.1.5 の変更:
  ・後から精度を見直すためのデータを記録するようにしました(解析の結果や画面の動きは変わりません)。
      - archive フォルダ: 解析した配信ごとに、1秒ごとの音量・チャット(草の件数・発言した人数・スパチャ)・コメント欄の時刻と文面の先頭60文字・解析ごとの設定と候補(直近5回分)を圧縮して保存します(2時間の配信で約40KB。最大2000本)。
      - cache/meta: YouTube の動画情報(みんなが繰り返し見た場面・チャプター・カテゴリ・タグ・再生数・登録者数)。yt-dlp で取得します(取れない動画・配信直後は記録なし。取れなくても解析はそのまま進みます)。
      - feedback.jsonl: 手動で切った区間を採用・不採用にしたとき、書き出したときも記録します。自動の候補には、最初の区間(auto0)と手で直した量(dStart / dEnd)、操作(adopt / reject / delete / export)も付きます。
  ・詳しい設定に「配信タイプ別の重み(試験的)」を追加(初期はオフ)。タイトル・タグ・カテゴリから、ゲーム/雑談/歌枠/その他を推定して重みの倍率をかけます(歌枠は音声×0.6、雑談は音声×0.8・チャット×1.1、いずれも仮の値)。タイプは手で指定もできます。オフでも、推定したタイプは記録します。
  ・改善のためにデータを送るときは、data.json・feedback.jsonl・archive フォルダをお渡しください。
  区間は点数の山を65%あたりに置き、近くの静かな所に端を寄せます。感度・本数・長さ・重みは②の設定で変えられます。
  チャットの取得は配信の長さ(チャット数)に比例して時間がかかります。複数本を解析するときは、今の配信の解析中に「次の配信のチャット」を裏で先に取っておきます(v0.1.3〜、同時に1本まで)。
  自分の番が来たときは待たずに使えるので、まとめて解析するほど全体が短くなります(1本だけのときは変わりません)。
  同じYouTube動画の再解析は、音量の解析結果とチャットをキャッシュ(cache/)から使うので速く終わります。配信中・直後の動画は「キャッシュを使わない」をオンに。

【フィードバック(自動で記録)】
  自動マークの「採用」・書き出し=「よかった」、「不採用」・候補のまま削除=「ちがった」として、feedback.jsonl に1行ずつ残ります(画面での集計はまだありません。感度・重みの見直し用)。

【旧ツールから消した機能】
  ・切り抜きマーカー: コメント欄からの候補抽出、CSV/TSV の出力・読み込み
  ・自動切り抜き: 見つけたらそのまま書き出す(自動書き出し)、○×ボタン(採用/不採用に置き換え)
  ・文字起こしツールは含みません(保留中)
  旧ツールのフォルダはそのまま使えます(このツールとは別のデータです)。

【データについて】(すべてこのフォルダ内)
  data.json(動画・マーク。壊れたときは data.json.corrupt-日時 に退避して新しく始まります。.bak は直前の控え)/ settings-ui.json / registry.json / config.json(APIキー)/
  feedback.jsonl / cache/(チャット・音量・グラフ)/ work/(作業用・自動で消えます)/ exports/(書き出し結果)
  他の人にフォルダを渡すときは config.json を抜いてください。解析結果のグラフは cache/series/ に保存され(最新60本)、再起動後も表示されます。

【できないこと・注意】
  ・笑い声や叫び声を聞き分けているわけではありません。大きい音・高い音の急上昇を見ています。ゲームの効果音・BGM・音量の急変にも反応します
  ・チャットのリプレイは、無効・削除された動画、メンバー限定チャットでは取れません(音声だけで判定します)
  ・メンバー限定・年齢制限・非公開の配信は取得できないことがあります
  ・縦動画(9:16)への変換・字幕の焼き込みはありません(横のまま書き出します)
  ・コラボのズレは今のところ手で指定するだけです(音声どうしの自動推定はまだ)。ズレが一定でない配信(回線落ち・広告の位置が動画ごとに違うなど)には、まだ十分に対応できません
  ・グループの基準の動画を外す(または動画ごと削除する)と、グループごと削除されます。すでに転写されたマークは残りますが、グループを作り直してズレを指定し直す必要があります
  ・YouTube から取得した映像には、著作権・利用規約が関わります。自分の配信や、許諾を得たものにだけ使ってください
  ・サーバーは自分のPC(127.0.0.1)だけで待ち受けます。外に公開しないでください

【困ったとき】
  ・途中で終了して黒い画面も閉じてしまう: v0.1.3 から、終了時に画面を閉じず理由を表示し、studio.log(このフォルダ)に終了の原因を記録します。
    起きたら、黒い画面のメッセージと studio.log(と studio.crash.log があればそれ)を教えてください
  ・画面の上に赤い帯: 古いサーバーが残っています。黒い画面を閉じて、start.bat を起動し直してください
  ・YouTubeのプレイヤーが出ない / 黒いまま: 必ず http://localhost:ポート/ で開いてください。広告ブロッカーが埋め込みを止めていないかも確認を
  ・「音声を取得できませんでした」: yt-dlp が古い可能性があります。yt-dlp -U で更新してください
  ・ポート8800が使用中のときは次の番号(8801…)で起動します。黒い画面に表示されたアドレスを開いてください
