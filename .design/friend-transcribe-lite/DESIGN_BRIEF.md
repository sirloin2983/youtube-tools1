# デザインブリーフ: 友人用 文字起こし簡易版

Oct 1, 2026 · @you

## 課題

文字起こしと字幕づくりを友人にも手伝ってもらいたいが、今の「編集」ツールは機能が多く、初見の友人には難しい。友人は動画編集の専門家ではなく、手順書なしで迷わず使える道具が要る。

あわせて、友人の作業結果を文字起こし精度改善の評価データとして回収したい。ただし字幕向けに整えた文章は正解データとして使えず、ルールを守らない作業が混じると評価が汚れる。

## 解決の形

友人は自分のPC(RTX 3060)で start.bat を起動し、一本道の4ステップだけを進める。カットはせず、字幕だけのパックを作る。

1. 動画ファイルを選ぶ(ドロップ)。配信者名を選び、元動画のURLは任意で入れる。
2. 文字起こしを待つ。
3. 校正する。聞こえたとおりに直し、話者を付け、開始・終了の時刻を直し、行ごとに確認済みにする。
4. 書き出す。Resolve用の字幕パックと、評価用zipが同時にできる。zipはDropboxのファイルリクエストで手動アップロードする。

字幕を読みやすく整える作業はResolve側で行う。

## 体験の原則

1. **選ばせるより固定する。** フォント・サイズ・位置・字幕分割は固定し、変えられるのは話者ごとの文字色とふちの色だけにする。設定変更による不具合と迷いを防ぐ。
2. **止めずに知らせる。** 長い動画や形式違いの警告は、数秒で消える軽い表示にとどめる。10分超は注意表示、30分超は確認ダイアログ(続行可)で、上限は設けない。
3. **間違いは弾くより起きないようにする。** 時刻の逆転や重なりは入力時に防ぎ、話者は既定値を必ず入れる。評価から弾くのは、画面で防げない違反だけにする。

## 文字起こしルールと評価データ

校正は「聞こえたとおり」に書き、行単位の時刻も直す。友人に渡すルールは次の4つで、ルールのバージョンを meta.json に記録する。

- 言った言葉はすべて書く(「えー」、言い直し、噛みも含む)。
- 聞き取れない部分は `[?]`、笑い声などは `[笑]` にする。
- 二人が同時に話したら、行を分けて話者ごとに書く。
- 言っていない言葉は足さない。

評価用zipは1作業につき1つで、ファイル名は `日付_配信者_作業ID.zip` とする。

| ファイル | 中身 | 用途 |
| --- | --- | --- |
| audio.flac | 16kHzモノラルの音声(10分で数MB) | 新しいモデル・設定での再実行 |
| asr\_raw.json | 生出力。単語ごとの時刻・確信度、モデル・設定・ツールのバージョン | 誤りの再現と比較の基準 |
| final.json | 校正後の行。テキスト・時刻・話者・確認済みの印・生出力との対応 | 文字誤り率、時刻、字幕分割、話者推定の正解 |
| edits.jsonl | 分割・結合・時刻修正の操作と、確定前に再生したか | 差分で復元できない操作の記録 |
| meta.json | 配信者名、出演者、元URL(任意)、長さ・fps、作業者名、日付、ルールとデータ形式のバージョン | 振り分け(如月れんは学習に入れない など) |

入れないもの:動画本体、PCのユーザー名を含む絶対パス(ファイル名だけ残す)、評価に不要なPC情報。

弾く条件は2つで、データは消さずに印と理由だけを記録する。判定はあなた側の取り込み時を最終とする。

- **記号の形式違い**(`【笑】` `(笑)` `w` など):その行だけを外す。
- **整えてしまった疑い**(生出力に比べてフィラーが大きく減っている):作業ごと外す。基準は最初のデータを見て調整する。

「聞かずに確定」は弾かず、記録だけ残す。聞き間違いは自動では見抜けないため、最初は一部の行を抜き取って聞き比べる。

## 画面と主要な操作

画面は「読み込み → 文字起こし中 → 校正 → 書き出し完了」の一本道で、戻る操作はいつでもできる。作業は自動保存され、ツールを閉じても次回は続きから再開する。

- **読み込み**:動画をドロップし、配信者名を選ぶ(必須)。10分超で注意表示、30分超で確認ダイアログを出す(どちらも続行可)。
- **文字起こし中**:進み具合と残り時間の目安を出す。キャンセルできる。
- **校正**:左に動画、右に字幕の行の一覧を置く。行をクリックするとその位置から再生し、Enterで確認済みにして次の行へ進む。話者は数字キーかプルダウンで付ける。時刻は「今の位置を開始/終了にする」キーと±0.1秒の微調整キーで直し、前後の行と重ならないよう入力時に制限する。再生キーは「編集」と揃える。波形表示は最初は付けない。
- **書き出し**:ボタン1つでResolve用パックと評価用zipを作る。直しやすい問題(記号の形式違いなど)は軽い通知で知らせ、書き出しは止めない。完了後はzipの入ったフォルダを開き、アップロードを案内する。

文言は専門用語を避け、手順書なしでも迷わない言い方にする。

## 見た目の方向性と既存パターン

「編集」のUI全面見直しと同じく、明るいテーマで落ち着いた仕事道具風にする。PCの全画面での利用を主とする。

- **トーン**:静かで迷わない。次にやることが常に1つだけ目立つ。
- **参考**:見直し後の「編集」の校正画面。共通の色・文字・余白・再生キーをそのまま使う。
- **避けたいもの**:設定や上級機能が並ぶ管理画面風の見た目、派手な装飾。

既存の色・文字・余白の定義(トークン)は、見直し後の「編集」から引き継ぐ。具体的な値は、実装時にリポジトリで確認して埋める。

## コンポーネント一覧

状態は「編集」の見直し後の実装を基準にした見込みで、実装時に確認する。

| コンポーネント | 状態 | 補足 |
| --- | --- | --- |
| 動画プレーヤー+再生キー | 既存を流用 | 「編集」とキー配置を統一 |
| 字幕の行の一覧(校正) | 変更 | 確認済みの印、話者、時刻の入力制限を追加 |
| 時刻の調整操作 | 新規 | 今の位置を開始/終了に、±0.1秒 |
| 話者リストと色の設定 | 新規 | 文字色とふちの色のみ、保存して再利用 |
| 読み込み画面(ドロップ+配信者名) | 新規 | 配信者名は必須、元URLは任意 |
| 進み具合の表示 | 既存を流用 | キャンセル付き |
| 軽い通知・確認ダイアログ | 既存を流用 | 長さ警告、書き出し時の警告 |
| 書き出し(パック+評価用zip) | 新規 | 中身は共通コアの処理を呼ぶ |
| 評価データの取り込みチェック(あなた側) | 新規 | 弾く判定の最終版。画面は最小限 |

## アクセシビリティ・セキュリティ・エッジケース

**アクセシビリティ**

- 校正の主要操作(再生、確定、話者、時刻)はすべてキーボードだけでできる。
- 文字のコントラスト比は4.5:1以上。確認済みかどうかを色だけで区別しない。
- 話者の色の候補は、黒ふちの上で背景に埋もれにくく、互いに見分けやすいものに絞る(白・水色・ピンク・黄緑など)。

**セキュリティ**

- 自動更新は取得元をあなたのリポジトリのmainに固定する。
- 書き出し時に、PCのユーザー名を含む絶対パスを取り除く。
- 届いたzipは信用しない。展開前に、想定外のファイルや `../` を含むパスがないか検証する。
- ファイルリクエストのリンクは友人にだけ渡し、不要になったら締め切る。共有フォルダは2人だけに限定する。
- 評価データの保存先は公開リポジトリの外にする。

**エッジケース**

- 記号を取り除いて空になる行は字幕にしない。余分な空白や連続した句読点は詰める。
- 行分割は記号を取り除いた後の文字数で行う。
- 時刻は秒で持つ。60fpsの横動画を30fpsのResolveプロジェクトで使ったときに字幕がずれないか、実機で確認する。
- 途中までしか校正していない作業は、確認済みの行だけを評価に使う。
- 同じzipの二重送付は、ファイル名の作業IDで見分ける。

- [ ] ホロカラーとの連携方法(友人PC上での形を確認してから)
