## Summary

ブリーフの形(appnav・⚙ の欄・キーの帯・1枚の紙の一覧・暗い舞台)は4画面にそろって入っている。見直しでいちばん大きかったのは、
**映像の上に重ねるはずの字幕が映像の下の道具の上に出ていた**ことと、**「…」と映像の下のカードで同じ操作の入口が2つあった**ことで、どちらも直した。

## Must Fix(この見直しで直した)

1. **字幕の重ねが映像の外に出ていた**: `.tt-caption` の基準が再生の道具まで含む `.tt-player` だったため、下から 6% が道具の辺りになっていた。
   See `review-edit-rowmenu-desktop-1440.png`(直したあと)。_Fix(済み): 映像と字幕だけの箱 `.tt-vbox` を作り、字幕は下から 14%(再生バーに重ならない)。音声だけのときは出さない。_
2. **同じ操作の入口が2つ(ブリーフの原則2)**: 話者・文字をまとめて直す・書き出し・以前の版の4枚のカードが映像の下にいつも出ていて、一覧の上の「…」はそこへ飛ぶだけだった。
   _Fix(済み): 4枚は閉じている間は隠し、「…」から開いたときだけ出す(`app.js` の `spDetails` など)。_

## Should Fix(この見直しで直した)

1. **キー操作の一覧の並びが画面・欄で違った**(共通の再生キーとスタジオは「説明 → キー」、編集は「キー → 説明」)。See `review-edit-keys-desktop-1440.png`。_Fix(済み): 全部「キー → 説明」に(`ui-kit.js` の `helpHtml`・`clip-studio/core.js`)。_
2. **⚙ の欄の中で形が違った**(ツールの節は名前の下に選択欄、全体の節は右に)。See `review-edit-settings-desktop-1440.png`。_Fix(済み): 選択欄の行は全部1行の形(`ui-kit.css` の `.ui-settings-sec .fld:has(>select)`)。_
3. **ホームの ⚙ だけ記号のみ**(ほかの画面は「⚙ 設定」)。_Fix(済み): 文字つきに。_
4. **文書を開くたびに「メニューを閉じました」のトースト**(1600px 未満)。_Fix(済み): 画面を開いている間に1回だけ。_

## Should Fix(残り)

1. **盛り上がりのグラフと山の札を見本のデータで確かめられない**: 系列は解析の直後にしか無いので、見本では出ない。_実機で解析したあとに確かめる(高さ・タイムラインとの横幅と時間のそろい・札の重なり)。_
2. **行の右クリックのメニューに届きにくい**: 行の大半は文字の欄で、その上ではブラウザ既定のメニュー(コピー・貼り付け)を残す決まりにしたため、メニューが出るのは時刻・話者・行の余白だけ。_使ってみて不便なら、文字の欄でも Shift+右クリックで出すなどを検討。_

## Could Improve

1. スタジオの再生の欄のボタンは −10s/−5s/+5s/+10s のまま(キーは ±1秒・Shift で ±5秒)。ボタンもキーに合わせて ±1/±5 にするとそろう。
2. スタジオのマークの一覧は1件ずつの編集カードのまま(開始・終了の調整ボタンが多い)。畳んだ行だけ1枚の紙にすると、ホーム・編集とそろう。
3. 編集の ⚙ の欄で「動画の大きさ」の選択欄だけ幅が広い。
4. 1024px の編集で、一覧の上の「…」が検索欄の下の行に1つだけ落ちる。

## What Works Well

- **暗い舞台と字幕の重ね**: 明るいテーマでも映像の周りだけ暗く、実際の字幕の見た目(けいふぉんと・ふち)で今の行が重なる。この道具の「見どころ」になっている
- **1枚の紙の一覧**: ホームの次にやること・案件、編集の行が、細い線で区切った1枚になり、カードの山より速く目で追える
- **appnav と ⚙ の欄**: 4画面で同じ位置・同じ形。全体の設定(テーマ・文字の大きさ・キーの帯)がどこからでも同じ
- **キーの帯**: 場面ごとに中身が変わる(行を選んでいる・入力中・端を選んでいる)。覚えなくても見える
- **幅への対応**: 1440px で編集のメニューを自動で閉じる・スタジオの書き出しの欄を 1680px 以上だけ並べる、で主役(映像と一覧)が狭くならない。390px でも横にはみ出さない
