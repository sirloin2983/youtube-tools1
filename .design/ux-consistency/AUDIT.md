## 4. 見つかった不整合・バグ候補

1. **speakerColors スイッチを autorun が無視する。**
   - スイッチは localStorage `tx.pk.speakerColors` で、ブラウザ限定。
   - 3 パックタブと zip はスイッチに従う。映像上の字幕色(`app.js capSpeakerColor`)も同じ値を見る。
   - autorun は常に ON。OFF のつもりで「まとめて実行」しても話者色が付く。
   - 原因は `_pack_one` が `output.speakerColors` を渡さないこと。cut2resolve の既定が ON。
2. **fps/大きさが autorun だけ設定を無視する。**
   - 3 パックの設定で 60fps や横を選んでいても、まとめて実行は 30fps・縦。
   - wrap も縦の値に固定される(`autorun.py:528` のコメントどおり意図的だが、設定画面には書かれていない)。
   - 横で作るとき、autorun は wrap も縦の値を使うため、タブや zip と字幕の改行が変わる。
3. **配信者の入力が入口ごとにバラバラ。**
   - 3 パックの `#pkWho` は文書ごとに記憶される。
   - 同じ編集画面の `#docAutoWho` は記憶なし。文書を開き直すと空になる(`app.js:1471`)。`pkWho` の値も引き継がない。
   - `#txBatchWho`、ポータル、スタジオも記憶なし。
   - 入れ忘れると黒字幕になる。
4. **rows パックの記録が非対称。**
   - autorun がカット無しの rows パックを作っても `/api/edit/pack` を呼ばない。
   - 履歴一覧は動画隣のフォルダで「パック済み」と出る(`txindex.pack_info`)。
   - 一方、3 パックタブの「前回のパック」は `edit.pack` を読むので空のまま。(要確認)
5. **rowEdge の形が不正なときの挙動が違う。**
   - zip と「行から」(`resolve_export._row_edge`)は既定に戻して警告を出す。
   - autorun は cut2resolve が ToolError(400)を返し、パック段が失敗する。
6. **配信単位の実行にはパック上書きの手段がない。**
   - 案件の行、スタジオ、探すのどれにもない。上書きは文書単位(入口の紐づかない文書リスト、編集)だけ。
   - 案件に紐づく文書は入口の文書リストに出ない(`unlinked` のみ)。ここから上書きする経路は無い。
7. **配信者の入力の有無が入口で違う。** スタジオの自動文字起こしは、文字起こしまでなので影響は小さい。
8. **wrap の下限が場所で違う。**
   - autorun と pack-tab は 0(改行なし)を許す。
   - `subtitle_settings`(`serve.py:2178`)は 2 未満を既定に丸める。
   - 影響は zip で wrap を渡さない場合のフォールバックだけ。
9. **文字起こしの元データが入口で違う。**
   - 新規パネルは画面の欄の値(`jobOpts`、`app.js:350`)を渡す。`glossary` と `splitChars` は画面値。
   - autorun は保存済み設定を使い、保存は変更の 0.6 秒後(`app.js:241`)。
   - 直後に別ブラウザから実行すると古い値になりうる。
   - 新規パネルは範囲指定、フォルダ一括(`/api/transcribe-batch`)、マーカーのポイント(前後余裕 `mPad`)も持つ。autorun にはこれらがない。

### 「?」の一覧を直接編集できる形にする手順
1. **描画を共通化する。** `UIKit.keymap`(ui-kit)に、定義表の登録・正規化・捕捉・描画を集めます。`?` の一覧と設定欄が同じ描画を呼びます。各行のキー表示を `<button data-id>` にして、押すとその場で捕捉に入ります(review.js:875 と app.js:2026 の実装を 1 つにします)。
2. **共通の再生キーを 1 か所に保存する。** 案: 入口の `api/ytt/keymap`(launch.py:736 の `ytt_api` に足す。POST のみで、ui-kit の `yttPost` から両ツールが呼べる)に保存し、`<作業データ>/app/keymap.json` に置きます。ツール固有の割り当ては今のまま各ツールに保存します。編集の settings.json の再生キー ID は、初回に共通へ移します。入口の外で開いたときは各ツールの保存にフォールバックします。
