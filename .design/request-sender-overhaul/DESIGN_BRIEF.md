# デザインブリーフ: 切り抜き依頼(RequestSender)の全面見直し

> 状態(2026-10-02): **実装済み**(送るアプリ 2.0.0・ホーム 0.23.0・スタジオ 0.14.0。見直しは DESIGN_REVIEW.md)。作ってから変えた所: 最小の大きさは 900×660・配色 B の誤りの色は橙 #FF8A3D・
> 空の時刻は `-:--:--`・時刻の入れ方の説明は左の列の下に固定・重みの欄は「指定する」を入れたときだけ出す・時刻の欄に右クリックのメニュー。
> 対象: `request-sender/`(友人のアプリ 1.4.0 → 2.0.0)と、受ける側の `home/intake.py`・`home/autorun.py`・`studio/`(API を1つ足す)。
> 経緯: ユーザーの依頼(時間を指定して切り取る・カットを選べるように・UI の全面見直し・便利な機能の提案)と、その後の聞き取り(2026-10-02)。

## 課題

友人は「この配信のここを切り抜いてほしい」と分かっているのに、今のアプリでは URL と「何個」しか伝えられず、どこが切り抜かれるかは自動まかせになる。
画面は縦に長い1列(高さ 840px)で、動画・URL・話す人・仕上げ方が上から順に積まれ、何を入れれば送れるのか、送ると何が起きるのかが一目で分からない。
時刻を入れる場所が無く、足すにしても「1:23:45」を「:」ごと打たせる形では面倒で間違えやすい。

## 解決の形

- 配信ごとに「切り抜く数」と「区間(開始〜終了)」を入れる。**区間が切り抜く数に足りない分だけ、PC が自動の見どころで埋める**(指定 1・数 3 なら 自動 2)。区間が数以上なら解析せず、その区間だけを取りに行く(速い)
- 時刻は **1つの欄**に、**時 → 分 → 秒 の順に数字だけ**で打つ(「:」は打たない)。←→ で触る場所を選び、↑↓ でその単位を動かす。YouTube で止めた位置の URL を貼ってもよい
- 画面は横2列: 左 = 送るもの、右 = 仕上げ方・話す人・メモ、下 = 送る内容の要約と「送る」
- 見た目はサイバー風(暗い地・細い線・等幅の数字・1色のアクセント)

## 体験の原則

1. **打たせるより、選ばせる・貼らせる。** 時刻は数字だけ・貼り付け・ボタン(+30秒 など)で入る。「:」や形式を覚えさせない
2. **送る前に、何が起きるかを見せる。** 「指定 1 + 自動 2」「① 全自動・カットしない」のように、今の入力で PC が何をするかを常に1行で出す
3. **邪魔をしない。** 知らせは窓の中とタスクバーだけ。窓を前に出さない・音を出さない・確認の窓を増やさない

## 大事な動き

### 時刻の欄(1つの欄・「:」は打たない)
- 表示は `0:00:00`(時は1桁、10 時間以上は2桁)。入っていない間は薄い色
- 欄に入ると「時」が選ばれている(反転)。数字を打つと **時(1桁)→ 分(2桁)→ 秒(2桁)** と自動で進む。`12345` → 1:23:45、`02345` → 0:23:45。分・秒で 6〜9 を最初に打ったら 1桁とみなして次へ
- ←→ で 時・分・秒 を選ぶ。クリックでも選べる。選んだ所は数字で打ち直せる
- ↑↓ は選んだ単位で ±1(Shift で ±10)。繰り上がり・繰り下がりあり。0 より前には行かない
- BackSpace = 選んだ所を 0 に(もう 0 なら左へ)。Delete = 欄を空に
- 貼り付け: YouTube の「現在の時刻の動画の URL をコピー」の URL(`?t=5025`・`t=1h23m45s`)と `1:23:45`・`83:45` を読む。URL の欄が空なら URL も入れる。読めなければ欄の下に赤で理由
- 終了が開始以下・60 分超は、終了の欄を赤い枠にして下に理由と直し方を出す(送るまで待たない)
- 「+30秒」などは 終了 = 開始 + その長さ
- 欄の下の説明に「10 時間より後の位置は、『時』を選んで ↑ か、URL の貼り付けで入れます」を出す(時は1桁で次へ進むため)

### 切り抜く数と区間
- 切り抜く数は 1〜10(前回の値を覚える。はじめは 3)。区間は 1配信に 10 個まで・1区間は 60 分まで
- いつも「指定 n + 自動 m」を出す。区間を足して数を超えたら、数を区間の数に合わせる(= 自動 0)
- ③ 全部人が行う のときは、切り抜く数・区間は灰色(送らない)。①② に戻すと入れた値はそのまま戻る

### 送るまで
- 下の帯に常に要約: 「配信 1 本(指定 1 + 自動 2)・動画 0 本・① 全自動・カットしない・トラック 1」
- 「送る」を押したら、足りない・誤りのある欄へ移して、その欄の下に理由を出す(まとめたエラーの文を下に積まない)
- 送っている間は進み具合を帯に出し、「やめる」を押せる。終わったら「送りました ✓」と、① なら「できあがると『受け取る』に届きます」

### 覚えること
- 覚える: カット・映像トラックの数・切り抜く数・見どころの重み(指定するか・3つの数字)・配色・窓の大きさ
- 覚えない: 仕上げ方(毎回 ①)・URL・区間・話す人・メモ

### 知らせ(邪魔をしない)
- アプリを開いている間、数分ごとに「出力」を確かめる。届いたら: 「受け取る ●n」・窓の題名に件数・タスクバーのボタンを数回光らせる(前に出さない・音なし・窓なし)
- 題名の問い合わせ(YouTube の oEmbed)は裏で行い、入力を止めない。失敗しても送れる(「題名を確かめられませんでした」と薄く出すだけ)

## アクセシビリティ

- キーだけで全部できる: Tab の順は 左の列 → 右の列 → 送る。時刻の欄は上の動き。区間の × は Delete でも
- 文字と地のコントラストは 4.5:1 以上(薄い説明の文も)。誤りは色だけでなく文でも出す
- 選ばれている所(フォーカス)はアクセント色の 1px の枠で必ず見える
- 部品に AccessibleName を付ける(時刻の欄は「開始の時刻」「終了の時刻」)

## 使いやすさの原則(Nielsen の 10。特に効かせるもの)

- **1 状態を見せる**: 「指定 n + 自動 m」・下の帯の要約と進み具合・題名の確認の ✓・届いた数
- **5 間違いを起こさせない**: 「:」を打たせない・終了 ≤ 開始をその場で赤に・③ のときは区間を灰色に・既定はカットしない
- **6 覚えさせない**: 時刻の欄の下に使い方を1行(YouTube で右クリック → 「現在の時刻の動画の URL をコピー」→ Ctrl+V)・前回の設定を覚える
- **7 柔軟さと効率**: 数字だけ / 貼る / ↑↓ / +ボタン の4通り。慣れた人は数字と貼り付けだけで済む
- **9 エラーを直せるように**: 誤りは欄の下に「何が・どう直す」。まとめて下に積まない
- **3 取り消せる**: 区間・配信の × 、送信中の「やめる」。8 必要なものだけ: ① 以外ではカット・トラックを灰色に、話す人の名前の欄は人数を選んだときだけ

## やらないこと(今回)

- 時刻のメモをまとめて貼る・区間に題名を付ける・送った依頼の進み具合(提案したが選ばれなかった)
- アプリの中で動画を再生して位置を選ぶ(.NET Framework 4 の標準の部品では YouTube を再生できない)
- 友人が前後の余白を選ぶ(PC が自動で付ける)
- 明るい/暗いの切り替え(選んだ配色1つだけ)
- ホーム・スタジオ・編集の画面の配色の変更

## 依頼の JSON に足すもの(アプリ 2.0.0 ⇔ ホーム 0.23.0)

```json
{"v":1,"kind":"url","id":"…","flow":"auto",
 "items":[{"url":"https://www.youtube.com/watch?v=xxxxxxxxxxx","top":3,"ranges":[{"start":5025,"end":5110}]}],
 "memo":"","speakers":{"count":2,"names":[]},"videoTracks":1,"cut":"none",
 "weights":{"audio":1.0,"chat":1.0,"comments":0.7},"sentAt":"…"}
```
- `items[].top`(1〜10)= その配信から切り抜く数の合計。配信ごとに持つ(1.4.0 までは全部の配信で同じ値だった)。区間があるときは 区間の数 以上
- `items[].ranges` = 区間の一覧(0〜10 個。0 個ならキーを書かない)。`start`・`end` は秒の整数(余白を付ける前の、友人が入れた値)。0 ≤ start < end・end − start ≤ 3600。flow が manual(③)のときは書かない
- `cut` = "none"(カットしない)/ "silence"(無音を削る)。flow が auto(①)のときだけ書く(動画・URL の両方)。`videoTracks` の後
- `weights` = 解析の重み。「重みを指定する」を入れたときだけ・kind が url のときだけ書く。3つとも 0.0〜3.0 の数(小数1桁)。`cut` の後・`sentAt` の前
- PC 側: 形が違う値は捨てて既定で進める(区間は、形が違うものだけ断って理由を知らせる)

## 決まったこと(2026-10-02 ユーザー)

1. 配色は4つから選べるように、窓の右上に切り替えを置く
2. 前後の余白は 2 秒ずつ(PC が自動で付ける)
3. 解析の重みは、音声・チャット・コメントの3つの数字を直接いじる
4. 「時」は1桁で自動で次へ。10 時間より後は ↑ か貼り付け、という説明を画面に出す
5. 時刻の欄は1つ。時 → 分 → 秒 の順に左から打つ(右から押し出す形は不採用)。←→ で場所を選ぶ。「+30秒」などのボタンは要る
6. 区間が切り抜く数に足りない分だけ自動で埋める。カットは「しない / 無音を削る」の2つ
7. 仕上げ方は毎回 ①。ほかの設定は覚える。URL の題名を出す。届いた知らせは邪魔をしない形だけ
8. 同じ配信も受け付け、解析などは使い回す。③ + 時間指定はやらない
