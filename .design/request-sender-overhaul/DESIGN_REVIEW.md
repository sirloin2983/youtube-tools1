## まとめ

設計書の柱(「:」を打たせない時刻の欄・送る前に何が起きるかを見せる・邪魔をしない)は画面に出ている。
見直しで見つけた大きな問題は「配色 B で誤りが誤りに見えない」「送り終えたことが目立たない」「最小の大きさで × が切れる」「③ のとき誤りの表示が残る」「時刻の欄の反転が Windows 標準の青になる」で、どれも直した。
残っているのは、友人の PC(本物のキー入力・DPI 125%/150%)でしか確かめられないことと、下の「余裕があれば」。

## 必ず直す(直した)

1. **最小の大きさで区間の × が切れ、右の列にスクロールが出る**(`review-send-min-900.png`)。→ 「長さ」の幅を詰め、最小の高さを 660 に、メモの最小の高さを 44 に
2. **③ を選んでも、区間の誤り(赤い枠と理由)が残る**(`review-send-manual.png`)。使わない欄の誤りを見せると「直さないと送れない」と読める(原則 5・8)。→ 使えない間は誤りを出さない(`RangeRow.Problem`)
3. **時刻の欄の「選んだ所」の反転が Windows 標準の青**(配色 B・C で浮く。いちばん大事な操作の見え方)。→ 欄を自前の描画にして、反転をアクセントの色に(`TimeBox.cs`)。文字を打ち込めない・日本語入力に取られないのも同時に解決
4. **Tab の順が見た目と違う**(「+ 配信を足す」が先・区間の行が「+30秒」の後)。→ 縦に積んだ順・カードの中は URL → × → 切り抜く数 → 区間 → ボタンの順に(`VStack.Arrange`・`StreamCard.Arrange`)
5. **配色 B の誤りの色が水色**で、誤りに見えない。文も「赤い所を直して」で色に頼っていた(原則 9・4)。→ B の誤りの色を橙に、文は「⚠ 直す所があります(枠の色が変わった欄の下に理由があります)」、欄の下の理由にも ⚠ を付けた
6. **送り終えたのに「送るものを入れてください」が上に出て、「送りました ✓」が小さい**(原則 1)。→ 送り終えたら帯の1行目を「送りました ✓」(太字・アクセント)に、2行目に次のこと。何か入れたら元に戻る
7. **時刻の欄はマウスだけだと貼れない**(右クリックに何も出ない。原則 7)。→ 配色に合わせた右クリックのメニュー(貼り付け・コピー・空にする)
8. **誤りの欄へ移すのが、窓が前に無いと効かない**(`Focus()`)。→ `Select()` に

## 直したほうがよい(直した)

1. **空の時刻が `0:00:00` で、値が入っているように見える**(`review-send-empty.png`)。→ 入っていない欄は `-:--:--`(欄に入ると `0:00:00` になり「時」が反転)
2. **開いた直後、最初にやることが弱い**。→ URL の欄に「ここに YouTube の URL を貼る(Ctrl+V)」を薄く出し、開いたらその欄にフォーカス。欄の下の文は「貼ると、ここに配信の題名が出ます」に(同じことを二度言わない)
3. **「配信の URL 0」「動画ファイル 0」の 0 が意味を持たない**。→ 件数はあるときだけ「配信の URL(2)」
4. **時刻の入れ方の説明が、配信が増えるとスクロールの外に隠れる**(原則 6・10)。→ 左の列の下に固定。文も「/」で区切って短く
5. **重みの欄がいつも出ていて、使わない人の右の列を押し下げる**(原則 8)。→ 「指定する」を入れたときだけ出す
6. **受け取る一覧(標準の ListView)が、暗い配色でスクロールバーか列の線のどちらかが標準の見た目になる**。→ 自前の一覧(`EntryList`)に
7. **配色の札に名前が無い**。→ 左に「配色」と書き、札にツールチップ(配色 A: ネオンシアン など)
8. **記号だけのボタン(×)に説明が無い**。→ ツールチップ(この区間を外す・この配信を外す)

## 余裕があれば(直していない。決めてほしい)

1. **− / + を押しっぱなしで連続して動かす**(重みを 1.0 → 2.0 にするのに 10 回押す)。今は1回ずつ
2. **開始を打ち終えたら、自動で終了の欄へ進む**(10 桁を続けて打てる)。打ち直しのときに勝手に移るので、好みが分かれる。今は Tab か Enter で進む
3. **配信が 2 本を超えると、左の一覧がスクロールになる**(1000×700 のとき)。窓を大きくすれば収まる。カードを畳める形(URL と要約の1行だけ)にする手もある
4. **題名の ✓ だけアクセントの色にする**・**「送る」の上に Enter キーの近道**(Ctrl+Enter で送る)
5. **標準のまま残っているもの**: 名前の候補(オートコンプリート)の一覧・ファイルを選ぶ窓・確認の窓(MessageBox)・URL の欄で文字を選んだときの青。Windows の部品なので配色は合わない
6. **右の列は話す人が 7 人を超えるとスクロールになり、メモが下に隠れる**(`review-send-weights-speakers.png`)。まれなので今のまま

## 確かめられていないこと(友人の PC・実機で)

- 本物のキー入力での時刻の欄(数字・← → ・↑ ↓ ・Ctrl+V・右クリック)と、日本語入力がオンのときに数字が入るか(欄では日本語入力を切っている)
- DPI 125%・150% での並び(大きさは DPI の倍率で計算しているが、この PC の 100% でしか見ていない)
- Windows 10 での暗いタイトルバー・暗いスクロールバー(だめなら標準の見た目になるだけで、動きは変わらない)
- 配信の題名の問い合わせ(YouTube の oEmbed)・届いた知らせ(タスクバーが光る・前に出ない)

## 良かった所

- **時刻の欄**: 数字だけ・← → で場所を選ぶ・↑ ↓・貼り付け・「+30秒」のどれでも入り、誤りはその場で欄の下に出る。状態の動き(`TimeEdit`)は画面と切り離してあり、テストがある
- **下の帯の要約**: 「配信 2 本(指定 2 + 自動 3)・① 全自動・カットしない・トラック 1」が常に出ていて、送る前に PC が何をするか分かる
- **配色**: 色・フォント・大きさが `Theme.cs` の1か所で、4つの配色とも同じ部品で崩れない。窓ごとの画像(`--screenshot`)で、あとからの直しも確かめられる
