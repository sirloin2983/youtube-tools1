# 配信ランキング v0.1.1(開発メモ)

期間とワードを指定し、大手VTuber事務所ごとに配信アーカイブを再生数順に一覧するローカルWebアプリ(serve.py + index.html、標準ポート8785、Python標準ライブラリのみ)。

## 依頼の内容(ユーザー)
- 期間とワードを指定 → 条件に合うYouTube配信アーカイブから「人気が高い」動画を一覧表示
- ブイチューバーの企業(大手のみ)ごとに表示。**対象事務所はホロライブ・にじさんじ・ぶいすぽっ!・ネオポルテの4つだけ**(v0.1.1 で seed をこの4つに絞った。画面で追加・削除は可能)
- 「人気」は再生数として実装(当初「姿勢数」と書かれていたのは視聴数の誤記と解釈。確認は取っていない)

## 設計判断
- **search.list(100ユニット/回)は使わない**。登録した各チャンネルの uploads プレイリスト(UU+チャンネルID[2:])を playlistItems で新しい順に読み(50本=1ユニット)、期間より古くなったら打ち切り → videos.list(50本=1ユニット)で再生数・liveStreamingDetails を取得 → ローカルで期間・ワード・アーカイブ判定。100ch×30日で約200〜300ユニット(無料枠は1日10,000)
- **所属チャンネルの一覧はAPIで取れない**ため、事務所ごとの登録制(data/registry.json)。seed.json は4事務所の名前と一部の公式チャンネルのハンドル(@hololive / @nijisanji / @Vspo77。Web検索で確認したもの。ネオポルテは未設定)のみ。所属タレントのIDは推測で入れていない
- 「公式から取り込む」: 公式チャンネルの channelSections(multipleChannels)に載っているチャンネルを取り込む。**公式がその一覧を出しているかは未確認**(出していなければ手動登録)
- 登録形式: @ハンドル / UC…ID / youtube.com/@… / /channel/UC…。/c/ /user/ 形式は非対応。ハンドルは forHandle(1ユニット)、IDは50件まとめて channels.list
- 期間は日本時間(JST)、配信開始時刻(actualStartTime、なければ公開日時)で判定。アーカイブ=liveStreamingDetails.actualEndTime あり(プレミア公開も含まれうる)。ショート除外=61秒以下
- ワード: NFKC正規化+小文字化、空白/カンマ区切り、OR/AND、タイトル+概要欄 or タイトルのみ
- キャッシュ: 同じ検索の一覧・動画詳細を30分メモリに保持
- 同時接続数は公式APIで取れないので使わない
- セキュリティ: 127.0.0.1のみ、Host/Origin/Sec-Fetch-Site検査、APIキーは config.json(0600)にのみ保存し画面に返さない、レジストリは入力検証(refの形式・件数上限 30事務所×400ch)、出力はエスケープ、リンクは youtube.com/watch?v=<11文字> のみ、サムネは ytimg.com のみ、CSVは数式インジェクション対策(先頭 = + - @ にアポストロフィ)、CSPメタ
- 切り抜きマーカーの config.json(隣のフォルダ)があれば、ボタンでAPIキーを引き継げる
- 既に起動して data/registry.json ができている環境では、seed の変更は反映されない(登録内容が優先)
