# 文字起こしツール v0.8.1(A/B 比較の設定別用語集)— v0.8.0 追補の続き

SERVER_VERSION / APP_VERSION は 0.8.1。納品は全体zip(transcribe-tool-v0.8.1-full.zip)。

## 変更点
- A/B の各設定(variant)に、その設定だけの用語集を書けるようにした。POST /api/abtest の variants[].terms(改行・カンマ区切りの文字列)
- 意味: glossary=false → 用語集なし(terms は無視) / glossary=true で terms が空 → 共通の用語集(+自動追加) / glossary=true で terms あり → その設定だけ、その語だけ(自動追加なし。最大200語)
- 同じ内容の設定は1つにまとめる(重複判定に terms を含む)。設定名: 「モデル / 用語集あり」「…用語集独自N語(先頭2語…)」「…用語集なし」。結果 JSON の variants[].terms に語を保存
- 用語の誤挿入・ヒットの集計対象(terms)は、共通+全設定の独自語の和集合
- 画面: 用語集にチェックした設定の下に入力欄。チェックの切り替えで再描画しても入力は保持
- 認識に渡る用語は initial_prompt 約150字・hotwords 300字で切られる(whisper_kwargs)。長い用語集は後ろが効かない。この切り詰めは変更していない

## 使い方の案(ユーザーの方針: まず用語集ありで1時間校正→一度立ち止まって考える)
- 校正した1時間分を正解に、「なし / 共通 / その動画に出る人だけ」の3設定で比べる。見る指標は CER・置換/脱落/挿入・用語の誤挿入
- 途中で用語集を書き換えない(params.glossary に認識時の内容が残るため、比較のときに混ざる)
