# 文字起こしツール v0.8.2(ホロライブ名簿)— v0.8.1 追補の続き

SERVER_VERSION / APP_VERSION は 0.8.2。納品は全体zip(transcribe-tool-v0.8.2-full.zip。hololive-roster.json を同梱)。

## 内容
- hololive-roster.json: 所属ごとの名前一覧(asOf 2026-09-22)。GET /api/roster が返す(load_roster が文字列に整える。読めなければ空)
- 画面: 設定の用語集の下に「ホロライブの名簿から追加」(所属にチェック→用語集に追加、重複は入れない)。A/B の設定別用語集にも「名簿から足す」
- 用語集の「認識に効く長さ」を表示: whisper_kwargs は initial_prompt を先頭150字、hotwords を300字で切る。画面は先頭N語まで効くと警告(GLOSS_PROMPT=150 を serve.py と揃える)。全員を入れると後ろが効かないので、動画に出る人・ユニットだけに絞る運用
- 名簿の更新: ファイルを直す(再配布時は roster 同梱)。所属IDが重複しない・名前が空でない・重複しないことをテストで確認
