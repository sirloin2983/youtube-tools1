# 切り抜きマーカー v1.0.0(完成)

YouTubeショート向けの切り抜きポイント記録・書き出しツール。ローカルで動作(serve.py + index.html)。

## 構成
- index.html(単一ファイル) / serve.py(標準ライブラリのみ、127.0.0.1) / start.bat / start.command / README.txt
- データ: data.json、APIキー: config.json、書き出し: exports/(動画名)/、ログ: exports/export-log.txt
- index.html の APP_VERSION と serve.py の SERVER_VERSION は必ず同じ値(不一致だと赤い警告バー)

## 主な機能
- YouTube埋め込み / ローカル動画ファイルの再生、ライブ対応、シアターモード
- キー配置の変更、今をマーク①〜⑤(ボタンごとに前後の長さ)、IN/OUT/追加、開始・終了の微調整(±0.5/1/5秒)
- コメント欄の時刻から候補抽出(★おすすめ度、順序切替)
- 書き出し: ffmpeg(ファイル) / yt-dlp(URL)、精密/高速、失敗分だけ再実行、動画ごとのフォルダ、書き出し一覧のCSV/TSV
- 書き出しは原画角のまま(縦型変換はしない方針)

## 未確認・注意
- Mac の start.command は未検証。実YouTubeでの yt-dlp 書き出しは利用者環境で成功を確認済み
- ライブ終了直後はアーカイブ未完成で失敗することがある(時間を置く)

## 見送った案
- 縦型(9:16)変換、近接ポイントの統合(必要なら再検討)、書き出し前プレビュー(不要と判断)
