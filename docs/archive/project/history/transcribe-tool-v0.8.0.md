# 文字起こしツール v0.8.0(左手だけの操作・タグ・保存データ)— v0.7.0 / v0.7.1 追補の続き

SERVER_VERSION と APP_VERSION は 0.8.0。納品は全体zip(transcribe-tool-v0.8.0-full.zip。transcripts/・settings.json・dataset/・models の中身は含めない。上書き展開しても消えない)。

## 要望と方針
- 「左手だけで作業できるようにシフト+何かに統一(WASD)」「今後使うかもしれないデータもついでに保存」「何度も長時間作業したくない」
- 方針: 校正は1回で済むよう、(1) 校正の最中に、あとで学習・声紋・再解析に必要な情報(音の状態のメモ・話者・機械の出力との対応・人が消した行)を取りこぼさず、(2) 元の動画に頼らず使える形(音声つき)で自動保管する

## キー操作(Shift + キー。入力欄の外だけ)
- Q -3秒 / W 前の行 / E +3秒 / R 聞き直し / A 前の未校正 / S 次の行 / D 次の未校正 / F 次の要確認 / Z 行を削除 / X 聞き取れない / C 声が重なる / V BGM・音が大きい / T 行の文字を直す / G 集中モード / B 移動で自動再生 / Space 校正済みにして次へ(すでに校正済みなら次へ進むだけ。解除はボタン) / 1〜9,0 話者
- 入力欄(textarea・text/search 等の input・select)にカーソルがあるときは無効(Shift+文字は普通に入力される)。Esc で抜ける。チェックボックス等にフォーカスがあっても効く(isTextEntry で判定。従来は checkbox にフォーカスがあると Space・Ctrl+Z が効かなかった)
- 行の移動はフォーカスを入力欄に移さない(操作キーが効き続けるように)。選んでいる行は枠(.nav)で示す。入力中の従来キー(Ctrl+Enter 聞き直し、Alt+Enter 校正済み→次の入力欄、Alt+1〜9 話者)は残した。Alt+↑↓/N/G/R/,/./[/]/Z は廃止(Shift 系に統一)。再生速度は選択欄のみ
- Space(Shiftなし)は再生・停止のまま。Shift+Space は校正

## タグ(音の状態のメモ)
- segments[].tags: unclear(聞き取れない)/ overlap(声が重なる)/ bgm(BGM・音が大きい)。サーバーで許可リスト検査(TAGS)。行をクリックまたは選ぶと、行の下にボタンが出る(付いている行は常時表示)
- **unclear の行は、精度測定(doc_metrics の is_ok)・A/B の対象行・校正済みの書き出し(scope=proofed)から除外**。保管データには role=unclear で入る(あとで使うか選べる)

## 保存データ(dataset/)
- 目的: 追加学習(LoRA)・声紋登録・別モデルでの再認識を、あとから校正のやり直しなしに行えるようにする。元の動画が移動・削除されても使える(音声を保管)
- 構成: dataset/index.jsonl(全体の一覧。unproofed は除く)、README.txt(形式の説明)、settings-snapshot.json(用語集・置換辞書など)、docs/<tid>/{doc.json(文字起こし全体)、lines.jsonl(全行。未校正も)、manifest.json、full.flac(その範囲の全体の音声。設定で切り替え)、audio/<key>.flac(行ごと。16kHz・モノラル・前後0.2秒。最大30秒)}
- 行の項目: kind(line/deleted/added)、role(positive=校正済みで unclear 無し / negative=機械が出して人が消した行で、校正した範囲の中 / unclear / unproofed)、text、original(機械の出力。古い文書は null)、start/end、orig_start/orig_end、speaker/speakerName(声が混ざる行は mixed)、tags、flag、changed、proofed、audio
- 音声は positive・unclear・negative だけ切り出す(未校正は切らない=容量を抑える)。切り出しは、全体の音声を1回だけ取り出し(音量補正なし)、そこから ffmpeg で行ごとに。**増分**: 行の時刻が変わらず、ファイルがあれば切り直さない。校正を外した行・時刻が変わった行の音声は消す。元のファイルが無くても、保管済みの full.flac から切り出せる(manifest.note に理由)
- 実行: 専用スレッド(ジョブの待機列とは別)。同時に1つ。空き 1GB 未満なら拒否(507)。API: POST /api/archive {tid?, full?}(tid 省略=校正済みのある全部)、GET /api/dataset(状況・合計・話者ごとの正解の秒数・文字起こしごと・更新あり/元の文字起こしが削除済みの印)。ファイルのダウンロード用エンドポイントは作らない(フォルダをコピーする前提)
- 自動保管(画面側、既定オン。settings の archiveAuto / archiveFull): 10分ごと(変更があれば)、別の文字起こしを開くとき、タブを離れるとき。「今すぐ保管」「校正済みのある全部を保管」ボタン。ツールバーに「保管: 済/更新あり/まだ」
- プライバシー: 声・会話が入る。dataset/ は配布から除外(README に明記)。クラウドに上げる場合は同意・規約確認
- 目安(画面に表示): LoRA は正解 2〜3時間分から、声紋登録は話者1人あたり数分〜十数分から
