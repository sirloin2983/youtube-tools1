# Resolve Free 21.1 実機確認手順: SRT → Text+

目的: cut2resolve が作る EDL・カット後 SRT を使い、DaVinci Resolve Free 21.1 でカットを再編集できること、SRT から Text+ 字幕を作成できること、フォント・スタイル・プロジェクトの受け渡しが成立することを、コピーしたテスト素材だけで確認する。

## 安全条件

- 本番プロジェクトや本番動画は開かず、テスト用に複製した素材と新規プロジェクトを使う。
- `ヘルプ → DaVinci Resolve について` でResolveの版・エディションを記録する。対象はFree 21.1。
- 21.1ではスクリプト機能の制限変更が報告されているため、過去版向けの実行手順を前提にしない。Freeでスクリプトが表示・実行できなければ、その時点で中止して「不可」と記録する。
- 第三者スクリプトは配布元・ライセンス・コードを確認してから使う。未確認のスクリプトやフォントを管理者権限で実行・インストールしない。
- フォントファイルは、ライセンスで再配布が許可される場合だけ同梱する。確認できなければフォント名だけを伝える。

## 事前準備

1. テスト専用の新規フォルダ(例: `Desktop\\resolve-textplus-test\\package`)を作る。既存フォルダを流用しない。
2. 20秒程度のコピー動画を用意する。元動画は変更せず、複製したファイルを使う。可能ならH.264・固定フレームレート・音声あり。
3. cut2resolveにコピー動画を読み込ませ、最低2つの残す区間と3件以上の字幕を用意する。短い字幕やカット境界近くの字幕も含める。
4. EDL・カット後SRT・cut-plan JSONを含むパッケージを書き出す。テスト中に入力素材を上書きしない。
5. Resolve版、素材のfps・解像度・開始タイムコード、字幕件数を記録する。

## A. EDLのカットと再編集

1. Resolveで新規プロジェクトを作り、コピー動画をメディアプールへ読み込む。
2. プロジェクト設定の `General Options → Conform Options` で `Assist using reel names from` を有効にし、`Source clip filename` を選ぶ。リール名はEDLで素材照合に使う短いIDで、このテストEDLでは動画名に合わせて `TEST35` にしてある。
3. `ファイル → 読み込み → タイムライン` からEDLを読み込む。照合を求められたらテスト用コピー動画を選ぶ。
4. 複数区間が並び、映像と音声が同じ位置で切れていることを確認する。
5. 1か所のカット境界を前後に動かし、前後の映像・音声が再生され同期することを確認する。
6. 元動画から削除区間の一部を戻し、削除部分を復活できることを確認する。
7. 保存・終了・再オープン後も編集状態が残ることを確認する。

合格: カット位置を変更でき、元動画から削除区間を復活できる。黒画面・オフライン・音ずれがない。

## B. SRT読み込み(比較用)

1. カット後SRTをResolveの字幕読み込み機能で取り込む。
2. カット直前・直後を含め、字幕時刻がカット後の台詞に合っているか確認する。
3. 文章と表示時間を変更できることを確認する。

ここで作るのはText+ではなく字幕トラック。SRTの本文・時刻が正しいことを先に確定する。

## C. SRTからText+への変換方法

### C1. Resolve標準機能

1. 字幕トラック／字幕クリップのメニューに「Text+へ変換」等があるか確認する。
2. 見つかった場合だけ、テストプロジェクトで3件を変換する。
3. 変換後にText+であること、本文・開始終了時刻・改行が維持され、個別編集できることを確認する。

機能がなければ「なし」と記録する。以前のユーザー環境で該当メニューは見つからなかったため、存在を前提にしない。

### C2. Resolve内スクリプト／第三者ツール

1. Free 21.1でスクリプトメニューまたはコンソールを利用できるか確認する。表示されない、実行できない、APIが拒否する場合は中止する。有料版購入や有料依存は前提にしない。
2. 候補ツールがFree 21.1対応を明記しているか、配布元・ライセンス・依存環境を確認する。依存追加が必要なら、導入前に確認を取る。
3. 信頼できる配布元から取得したコードだけを、テスト用の空プロジェクトで実行する。
4. まず3字幕だけ変換し、Text+の本文・タイムライン時刻がSRTと一致するか確認する。
5. 成功後に全字幕を試す。失敗・クラッシュ・ズレが出たら本番素材に進まず、Resolve版・ログ・画面を記録する。

合格: 字幕数が一致し、Text+の本文・表示時間・スタイルを個別編集でき、Resolve再起動後も維持される。実行方式と追加インストールの要否を記録する。

## D. フォントとスタイル

1. 代表的なText+でフォント名・サイズ・色・縁取り/影・位置・揃えを設定する。
2. 複製または一括適用で全字幕に意図したスタイルが反映されるか確認する。
3. 指定フォントがない場合の警告・代替表示を確認する。
4. フォント名・ウェイト(Regular/Bold等)・サイズ・色・位置を記録する。
5. フォント本体は再配布許可が確認できた場合だけ渡す。DRT/DRPにフォントが埋め込まれるとは扱わない。

合格: フォントとText+設定がResolveで表示・保存される。別PCに同じフォントがなければ置換されうることを記録する。

## E. DRT/DRPと別フォルダからの復元

1. Text+を含む状態で保存し、実際に使う候補のDRT(タイムライン)またはDRP(プロジェクト)を書き出す。
2. Resolveを閉じ、テストパッケージ全体を別の新規フォルダへコピーする。元のテストデータは削除しない。
3. コピー先のDRTを新規プロジェクトへ読み込む、またはDRPを開く。元パスへの依存を調べるため、コピー先を優先して素材を再リンクする。
4. カット境界の編集・削除区間の復活・音声同期・Text+本文/時刻/スタイルを再確認する。
5. EDL・SRT・cut-plan JSONが復旧用として残っていることを確認する。

合格: 別フォルダからタイムラインとText+を復元できる。再リンクが必要なら、友人向け説明に実際の操作手順を記録する。DRT/DRPに動画素材が必ず内包されるとは想定しない。

## 判定

1. EDLのカットを安全に再編集できるか。
2. SRTの時刻がカット後タイムラインと合うか。
3. Free 21.1でText+を作る現実的な方法があるか。
4. Text+スタイルとフォントを別環境で扱えるか。
5. DRT/DRPを別フォルダへ移して復元できるか。

3が不合格なら、確認済みのEDL + SRTを納品形式として維持し、Text+自動生成の実装を保留する。Studio限定機能や再配布不可フォントを前提にしない。
