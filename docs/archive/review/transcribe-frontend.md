### 直さなかった・見送ったこと
- **1列(編集欄が 780px 未満)のとき、固定した映像の欄が画面の大半を占める**(390 幅で約 700px)。「1列のときは映像の欄を一覧の上に固定」は決定事項なので変えていない。行のスクロール位置は、固定した欄の下に隠れないように直した(`scroll-margin-top` に映像の欄の高さを足した)。狭い画面で使うなら、1列のときは道具の段を畳むなどの案がある(ユーザーに判断してほしい)
- 行の時刻を直して Enter/他所をクリックすると、一覧を描き直して直した行にフォーカスを戻す(クリックした先の入力欄にはフォーカスが行かない)。以前からの動きで、並び順が変わる場合に必要なので残した
- 行の一括選択の見た目は CSS の `:has(.sel:checked)` のまま(4000 行の速さの試験で問題なし)
- 修正データの書き出し(音声つき)が HTTP の処理の中で同期的に動く件は、サーバー側の報告どおり(画面は「数分かかることがあります」の表示のまま)

## 3. 追加した機能と使い方
1. **URL での受け取り**(docs/pipeline.md 3): `http://localhost:8775/?media=<動画のパス>` / `?clip=<.clip.json のパス>`。メニューの「新規」を開いてファイル欄に入れるだけで、**文字起こしは始めない**(案内を出す)。読んだら URL から `media`・`clip` を消す(ほかの値は残す)。`?clip=` だけのときは、サーバーの `mediaPath`(.clip.json が指す動画)を入れる
2. **元の配信の表示**: `GET /api/clip-info` で「元の配信: タイトル 20:34〜21:19 ・「マーク名」」。見つからない・壊れている・ネットワークのパスのときは、サーバーの理由(warning)を黄色で出す。ファイル欄に手でパスを入れたとき(change)も調べる。clip のある文書は、編集画面のタイトルの下にも出す。YouTube の配信は、その位置(`&t=秒s`)へのリンク
3. **動画の隣に保存**(「話者・置換・書き出し」の中): 文字起こし(.transcript.json)・字幕(.srt)・残す区間(.cut-plan.json)。保存の完了を待ってから `POST /api/export-file`(`baseUpdatedAt`、字幕は上の折り返し・話者名の設定を渡す)。保存したパスとコピーのボタン、**「cut2resolve で開く」**(`UIKit.tools.url('cut2resolve', ports, '/?video=…&transcript=…')`。ポートは `/api/siblings`、失敗したら既定)
4. **「他のツール」メニュー**: 開くたびに `/api/siblings` を問い合わせ、起動していないツールは灰色+「起動していないようです」(スタジオと同じ)
5. **テーマ**: ヘッダーの ☾/☀ と「表示」の「画面の色」は同じ設定。OS に合わせる/明るい/暗い
6. **細かい改善**: 操作キーの一覧を目的別(移動・聞く・校正・メモと編集・入力中・画面)に・空の状態の案内(手順 1〜3)・保存の状態の色の印(緑=保存済み/紫=保存中/赤=競合・失敗)・ブラウザのタブの題名に文書名と「●」(未保存)・文字起こしの完了/処理の失敗のお知らせ(メニューを閉じていても分かる)・通知の種類の色(ok/err/info)と押すと消える・ジョブの `warnings`(.clip.json の不正など)と `hasClip` を処理状況に・一覧に「元の配信あり」・サーバーの起動時の確認(`envWarnings`)をメニューの上に・Resolve の「選択行をカット/残す」に件数の通知

## 4. 配置・見た目の判断
- 決定事項(2列の配置・☰/G のメニュー開閉・行の ▶ は単独再生・単体キーと Shift+Space・選んだ行の下の操作の段・今の行と一括選択の区別・navSnapshot/navRestore・mousedown でフォーカスを移さない)はすべて維持(e2e_ui_v098 の 135 項目で確認)
- 映像の列の幅は「最大 460px(メニューを閉じたら 540px)」を保ちつつ、編集欄の 40%(42%)を超えないようにした。1024 幅で一覧が 436px → 560px に広がり、話者の欄が潰れなくなった(校正の主役は一覧のため)
- 行の配置は、一覧が 700px 未満なら2段(1段目「□ ▶ 時刻 話者 状態」、2段目に文字)、それ以上は1段。520px 未満は時刻の欄を詰める
- 「今の行」は 3px の太枠だけ(影は付けない)。影・保存中の点滅・行の枠線のアニメーションは、4000 行での移動のたびに描き直しが増えるので付けなかった(下の速さを参照)
- 左メニューのタブ・入力の種類の切り替えは、ui-kit の `.ui-tabs` / `.ui-seg` と同じ見た目(クラス名はテストが使うので既存のまま)
- 新しく足したクラスは `tt-` 付き(`tt-clip` `tt-handoff` `tt-kgrid` など)。既存の id・class・data 属性は変えていない(ヘッダーは `class="ui-header top"` で `header.top` を残した)
- API の URL は `apiUrl()` を通す(`api()`・新設の `apiBlob()`・動画の src)。統合時にベースのパスを1か所で変えられる(docs/pipeline.md 5)

## 6. 未確認のこと・リスク・判断してほしいこと
