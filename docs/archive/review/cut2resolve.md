## 直した問題(コミット 5456437)
| 重要度 | 内容 |
|---|---|
| 中 | タイムコードの指定の誤りが、粗編集の mp4 を書き出したあとで初めてエラーになっていた(重い処理の前に検査) |
| 中 | 粗編集・パックの書き込みが途中で失敗・取り消しされると書きかけが残った(一時ファイル → 置き換え) |
| 中 | ffmpeg/ffprobe に相対パスで渡していたため、「-」で始まるファイル名をオプションと取り違えうる(絶対パス・-nostdin) |
| 中 | FCPXML(auto_cut / srt2resolve)で開始タイムコードが asset の start に入らず、タイトルの offset・text-style-def の id も不正になりうる。**EDL の書式(Resolve 実機で確認済み)は変えていない** |
| 低 | 時刻リスト: 全角数字・CSV を読めない、分・秒の欄の 60 以上を黙って受け付ける、0 フレームの区間を警告しない |
| 低 | cut-plan.json に読み直しに必要な情報(tool / createdAt / media / segments)が無い |

## 追加したもの
- `pack.py`: 画面とコマンドが同じ関数でカット計算・パック作成を行う(処理を二重に持たない)。進み具合と取り消し
- 専用の画面: `serve.py`(127.0.0.1、既定 8810、Host / Origin / Sec-Fetch-Site の検査、他ツールからのリンク遷移だけ許可・iframe は拒否、Windows は SO_EXCLUSIVEADDRUSE、`.runtime/cut2resolve.json`、`/api/siblings`)、`index.html` / `app.js` / `app.css`(ui-kit、CSP でインラインスクリプト禁止)
  - 入力: 動画はパスで指定(ブラウザのドロップでは場所が分からないため)。字幕・文字起こし・cut-plan はドロップ可 → `work/uploads/` に写す(大きさの上限あり、40 件を超えたら古い順に削除、起動時に全削除)
  - カットの決め方: 無音 / 残す区間(cut-plan・文字起こしの行)/ 時刻リスト。試算でタイムラインに残す・削る・無音・字幕を表示、カット後の長さ、カット後の見え方のプレビュー
  - 余白の既定: cut-plan は 10 秒、文字起こし由来は 0 秒(行単位の区間が全部つながってしまうため。文字起こしの担当からの指摘)
  - 書き出し: 既存の出力があると確認のダイアログ → 上書き。結果の一覧・フォルダを開く(このサーバーが書いたフォルダだけ)・友人へ.txt の表示・粗編集の再生
  - `?video=&srt=&transcript=&plan=` で入力欄を埋める(自動実行しない、読んだあと URL から消す)
- `start.bat`(CRLF)/ `start.command`、`README.txt`(新規)、`e2e_ui.py`
