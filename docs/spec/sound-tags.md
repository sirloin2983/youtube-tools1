# 行の「音の状態のメモ」の付け方

状態: 規則(2026-10-06。BGM の基準をユーザーが決めた。ほかの 2 つは今の意味を書いただけ)

校正画面の行のメモ(`editor/ed_state.py` の `TAGS`)。キーは X / C / V(キー配置で変えられる)。

## どこで使うか(付け方を決める理由)
- 精度の評価: 条件ごとの間違いの率(`dev/eval_asr.py` の条件別)と、定点の条件「BGM 30 秒」「重なり 30 秒」(`editor/ed_drill.py` の `DRILL_CONDS`)
- 声の登録: `overlap`・`bgm`・`unclear` の行は声として覚えない(`editor/ed_speakers.py` の `VOICE_LEARN_TAGS`)
- `unclear` の行は精度の測定と学習の正解に使わない

付けすぎると「BGM の行」と通常の行の差が出なくなり、声を覚える材料も減る。だから「鳴っている」ではなく「聞き取りの邪魔をしている」で決める。

## BGM・音が大きい(`bgm`・V)— 2026-10-06 ユーザー決定
付ける:
1. BGM のせいで聞き直したくなった行(いちばんの物差し)
2. BGM・ゲーム音が声と同じくらいか、それより大きい行
3. 歌詞のある曲(歌声)が流れている行(声より小さくても。歌詞を文字にしてしまうことがあるため)
4. 効果音・ゲーム音が言葉の一部にかぶって聞きにくい行

付けない:
- BGM が鳴っているのは分かるが、1 回で楽に聞き取れる行(普段の配信の BGM はほとんどこれ)
- キーボード・マウスの音、小さな生活音
- 他の人の声(→「声が重なる」)
- 言葉の合間だけ BGM が大きく、言葉にはかぶっていない行
- 迷う行

経緯: 最初は「話し声の 6 割の大きさ以上」を考えたが、音量の割合は耳で毎回同じに判断しにくいので、聞き取りへの影響で決めることにした。
この基準より前に付けた行は、ユーザーが聞き直して付け直す(ゲーム実況・歌の入る動画は付け忘れも確かめる)。

## 声が重なる(`overlap`・C)
2 人以上の声が同時に聞こえる行。BGM と重なりが両方あれば両方付けてよい。

## 聞き取れない(`unclear`・X)
人が聞いても文字が決められない行。精度の測定と学習の正解に使わない。
