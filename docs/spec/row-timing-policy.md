# 行(字幕の区間)の時刻の決め方の原則

状態(2026-10-07): **決まり(ユーザー決定 2026-10-07)**。これに沿った後処理の直し方は `plan/line-b-row-timing.md` の 7(編集 0.57.1 で実装済み)。1 秒丸めの配り直しは測り直しで 1 に反したので 0.59.4 から既定オフ(同 6・8)。

## 原則(優先順位。上ほど大事)
1. **文字起こしした発言が、行の区間の時間にちゃんと収まっていること**(言葉の頭・末が切れない)
2. その次に、**前後の発言が区間に入らないこと**
3. その次に、**喋っていない時間を区間から除くこと**

迷ったら上を優先する。たとえば「前の行の終わり」と「次の行の始まり」がぶつかるときは、どちらの言葉も切らない方を選び(1)、それでも決まらなければ前後の発言が入らない方(2)、最後に無音を除く(3)。
無音を含める(3 を崩す)ことは、言葉を切る(1 を崩す)より常にまし。

## 測り方(この原則で「良い・悪い」を数えるときの定義。人が直した行を正解とする)
| 記号 | 何を数えるか | 判定(0.1 秒の余裕を見る) |
| --- | --- | --- |
| ①頭 | 発言の頭が切れる | 機械の始まり > 人の始まり + 0.1 |
| ①末 | 発言の末が切れる | 機械の終わり < 人の終わり − 0.1 |
| ②前 | 前の発言が入る | 機械の始まり < 前の人の行の終わり − 0.1 |
| ②次 | 次の発言が入る | 機械の終わり > 次の人の行の始まり + 0.1 |
| ③ | 喋っていない時間 | 人の区間の外へはみ出した秒(前後の合計)。中央・平均 |

## 今ある後処理をこの原則で見ると
| 後処理(`editor/ed_jobs.py`) | 今の動き | 原則との関係 |
| --- | --- | --- |
| `trim_ends`(`END_TRIM` 0.1 秒。2026-10-05) | 続いている行(すき間 0.3 秒以下)の終わりを 0.1 秒早める | **1 に反する**(末を切る方向)。10-05 の目安は「この行だけ再生」で聞くための値で、字幕の区間の原則とは別だった → やめる(計画 7-1) |
| `clip_rows` | 音声の長さより後ろを捨てる | 原則に関係ない(長さの外) |
| `merge_repeats` | 同じ 1 文字の行をまとめる | 時刻は最初〜最後(1 を守る) |
| `pull_ends`(既定オフ) | 行の終わりを音の谷へ早める | 1 に反しやすい(10-05 に「前で切れすぎる」)。オフのまま |
| `split_segment` | 行を単語の時刻で分ける・行の端を最初と最後の単語へ | 1 を守る(単語の時刻が正しければ)。3 にも効く |
| 1 秒丸めの配り直し `quant_retime`(0.57.0。**0.59.4 から既定オフ**) | 丸まった窓の行の端を聞き直した単語の時刻へ(`TRANSCRIBE_RETIME=1` のときだけ) | 1 を守るつもりだったが、聞き直した単語の終わりが言葉の末より早く **1 に反した**(①末 11% → 46%。計画 6 の測り直し)→ 既定オフ。丸まった窓の残りのずれは計画 8 |
| 続いている行のすき間 | 0.1〜0.5 秒のすき間が残る(字幕が一瞬消える) | 3 だけに沿っていて 1 を崩している。**前の行の終わりを次の行の始まりへ延ばす**と 1 が良くなり(①末 34% → 20%)、2 は少し悪く(②次 6% → 10%)、3 は少し増える(平均 0.46 → 0.51 秒)= 原則の順位どおり良くなる(計画 7-2) |
