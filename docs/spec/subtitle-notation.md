# 字幕の書き方の規則(校正の正解のそろえ方)

状態: 規則(2026-10-06。Claude Code が下書きし、ユーザーが決めた: B の正規化は全部入れる(編集 0.56.2 で実装)・笑い声は書かない。**A-5「えっ」と「え」は要検討**(人の側も揺れているため))

校正で直した文字は、**字幕**であり、同時に精度を測るときの**正解**でもある。書き方が人や日によって揺れると、
機械が正しく聞き取っていても誤りとして数えられ、CER(文字の誤り率)が実際より悪く出る。エンジンどうし・クラウドとの比較も表記の差で揺れる。
この文書は (A) 人が校正で書くときの規則と、(B) 採点で同じものとみなす違い(`editor/ed_learn.py` の `norm_cer`)の 2 つを決める。

`docs/plan/accuracy/USER_INPUT.md` の 7 と、計画 第2版(`docs/plan/transcription-plan-v2.md`)の 3-4 の答え。音の状態のメモは別の文書 `docs/spec/sound-tags.md`。

## 下書きの元(2026-10-06 に調べたこと)
- 校正済みの行で、人の最終と機械の出力が違う 109 組(評価用の確かめ済み 15 本 + 途中の文書)を、違いの種類で分けた
- 表記の違いで目立ったもの:
  - **伸ばし棒の数**: 機械「イエターーーーー」「アーーーーーーーー」「はぁーーー」 → 人「イテー」「アー」「はぁー」。1 本(さくらみこの叫びのショート)が CER 67.7% になった主な原因
  - **呼び名のかな・カタカナ**: 機械「ふわもこ」→ 人「フワモコ」、「はーちゃま」→「はあちゃま」、「ラミー」→「ラミィ」
  - **人の側の揺れ**(同じ文書の中でも): 「ラミィ」と「ラミー」・「こより」と「コヨリ」・「まぁ」と「まあ」・「えっ」と「え」・「あっ」と「あ」・叫びの「イテー」と「いってー」
- 人が書き足したつなぎ言葉(「あの」「えーっと」「うーん」「あっ」)は多い = つなぎ言葉は残して書いている
- 数字は機械も人も算用数字(「50回」「2泊3日」「10月11月」)。熟語の数(「三角」「四角」)は漢字
- 笑い声・英字の行は、今のデータにはほとんど無かった

## (A) 校正で書くときの規則
1. **言った言葉はすべて書く**。つなぎ言葉(えー・あの・えーっと・うーん)・言い直し・噛み・繰り返し(「いやーいやーいやー」)も、聞こえた回数だけ書く。言っていない言葉は足さない
   (友人用の規則 `ytt_core/evaldata.py` の `RULES` と同じ)
2. **伸ばし棒は 1 つ**(「イテー」「アー」「すごーい」)。どれだけ長く伸ばしても 1 つ。「〜」でもよい(採点では同じ)
3. **人の名前・呼び名は決まった表記**。名前は名簿(`editor/hololive-roster.json`)の表記(ラミィ・こより)。呼び名は本人・ファンの定番の表記
   (はあちゃま・ねねち・あちゃま・フワモコ)。迷ったら `docs/plan/accuracy/USER_INPUT.md` の 1 に足していく
4. **数字**: 数・回数・日付・時刻・金額は算用数字(50回・2泊3日・10月)。熟語の中の数は漢字(一緒・一番・三角)
5. **感動詞の小さい「っ」(要検討。10-06 ユーザー「人も表記が揺れているので要検討」)**: 案は、短く切ったら「えっ」「あっ」、伸ばしたら「えー」「あー」、それ以外(文の頭で軽く言う)は「え」「あ」
6. **「まあ」と「まぁ」**: どちらでもよい(採点では同じ。下の B-3)。字幕で見やすい方
7. **叫び・感嘆**のひらがな・カタカナはどちらでもよい(採点では同じ。B-2)。字幕で見せたい方
8. **笑い声は書かない**(「www」「(笑)」も付けない)。笑いながら言った言葉は書く。
   今の編集の字幕は人の最終の文字がそのまま字幕になるため(友人用の評価データの `[笑]` は、Resolve の字幕から消す仕組みがある別の流れ)
9. **英単語**は字幕で見やすい方(カタカナが多い。ゲームの固有名詞は公式の表記)
10. **聞き取れない所**は推測で埋めず、行に「聞き取れない」のメモ(X)を付ける(`docs/spec/sound-tags.md`)。その行は採点と学習に使わない

## (B) 採点で同じものとみなす違い(`editor/ed_learn.py` の `norm_cer`。編集 0.56.2 で実装)
今の `norm_cer`: NFKC・小文字・〜/~ → ー・句読点や記号や空白を数えない(10-04 に決めた)。これに足す:
1. **伸ばし棒の連続は 1 つ**(「ーーーー」→「ー」)。A-2 の規則と同じ。機械が伸ばし棒を多く出す癖は、聞き取りの誤りではないため
2. **カタカナはひらがなとして比べる**(「フワモコ」=「ふわもこ」)。CER は「聞き取れたか」を測るもので、字幕としてどちらで書くか(A-3・A-7)は別の問題のため。
   名前の表記の正しさは、別の物差し(名前・用語の再現率)で見る
3. **小さい母音(ぁぃぅぇぉ)は大きい母音として比べる**(「まぁ」=「まあ」・「はぁ」=「はあ」)。「っ」と「ゃゅょ」は残す(音が違う。「えっ」と「え」の扱いは A-5 が決まってから見直す)
4. 同じ小さいかな(母音・っ)の繰り返しは 1 つ(「オォォォォ」→「おお」・「あっっっ」→「あっ」)。B-1 と同じ考え

実装後の実測(10-06。15 本): CER 9.3%(95% の範囲 5.9〜13.6%)・時刻によらない CER 8.0%・名前と用語の再現率 47.5%(19/40)。下の試算と同じ

試算(2026-10-06。評価用の確かめ済み 15 本・10.3 分。コードは変えず、手元で `norm_cer` を差し替えて `dev/eval_asr.py stored` を流した):

| 正規化 | CER | 95% の範囲 | 時刻によらない CER | さくらみこの叫びの 1 本 |
|---|---|---|---|---|
| 今 | 13.0% | 7.2〜22.5% | 11.5% | 67.7% |
| + B-1 伸ばし棒 | 10.8% | 7.2〜15.2% | 9.3% | 30.6% |
| + B-4 小さいかなの繰り返し | 10.8% | 7.2〜15.4% | 9.4% | 31.9% |

- 伸ばし棒だけで 2.2 ポイント下がり、範囲の上の端が 22.5% → 15.2% に狭まる(1 本の外れ値に引っ張られなくなる)
- カタカナ = ひらがなは、さらに 1.4 ポイント。主に「ふわもこ」→「フワモコ」の 1 本(13.6% → 2.4%)

### 採点を変えるときに気をつけること
- 正規化を変えると、変える前の CER と比べられない。10-03 の入れ直しで以前の記録は失われていて、今あるのは 15 本だけなので、変えるなら今が一番安い
- `norm_cer` を使うのは採点の側だけ(CER・名前と用語の再現率・重なりの並べ方・「直しが無い文書は数えない」の判定。10-06 に grep で確かめた)。字幕の文字・置き換え辞書は変わらない
- 名前・用語の再現率も同じ正規化で数えるので、「ふわもこ」が当たり扱いになる(試算で 13/33 → 19/40。用語の数も正規化で変わる)。
  表記まで合っているかを見たいなら、正規化しない再現率を別に出す
