# ユーザーに入力してほしい項目(精度改善用)

このファイルに書き込むだけで大丈夫です(わかる所だけ・箇条書きでOK)。AI(Claude・GPT)が読んで、用語集・置換辞書・評価セットに反映します。
優先度は `docs/accuracy/accuracy-baseline.md` の結果から決めています(★が多いほど効果が大きい見込み)。

---

## ★★★ 1. 人物の呼び名・愛称
実際の修正で一番多かったのが、呼び名の聞き違い(トーイ→トワ、マチョ→まちゅ、すぅー→スバル、トルカ→ポルカ、みく→みこ、ヘヨ→ミオ)でした。
正式な名前(白上フブキ など)は話し言葉にほとんど出ないので、**配信で実際に呼ばれる形**を書いてください。

書き方: `正式な名前 = 呼び名1・呼び名2・…`(自分のことを何と言うか・他の人からどう呼ばれるか、どちらも)

```
例) 白上フブキ = フブキ・白上・フブちゃん・フブさん
大空スバル = 
さくらみこ = 
夏色まつり = 
兎田ぺこら = 
常闇トワ = 
尾丸ポルカ = 
大神ミオ = 
鷹嶺ルイ = 
ロボ子さん = 
(ほかによく出る人)
```

## ★★ 2. 聞き違えやすいが、置き換えてはいけない言葉
「みく→みこ」のように、普通の言葉と重なる呼び名があります。**別の意味でも使われる言葉**を書いてください(置換辞書で一律に置き換えないようにするため)。
```
例) みこ(巫女の意味でも出る)
```

## ★★ 3. 評価用の動画(精度を測るためだけに取っておく動画)
今の評価用は 2.6 分・2 人だけで、正式な評価には足りません。**合計 15〜30 分・4 人以上・元の配信 3〜5 本以上**が目安です。
学習・辞書には使いません。1本 30秒〜3分くらいの場面を集めてください。

| URL またはファイルの場所 | 配信者 | 区間(例 1:23:45〜1:25:00) | 場面の種類 | 評価用/学習用 |
|---|---|---|---|---|
| | | | 通常・重なり・BGM・小声・叫び・笑い・固有名詞・無音 のどれか | 評価用 |
| | | | | |

- 特に足りない場面: **重なり声(コラボ)**・叫び/笑い・固有名詞が多い場面・学習に入れない人(汎化の確認用。如月れん など)
- さくらみこの評価用 4本(教師データ＿さくらみこ02〜05)は、まだ校正されていません。校正すると評価用が約 3 分増えます

## ★★ 4. コラボの別視点
重なり声の誤り率が 24%(通常の約3倍)でした。同じコラボを、他の参加者が自分のチャンネルで配信している場合は、その配信の URL を書いてください
(その人の声がはっきり入っているので、重なった所だけ聞き直すのに使えます)。
```
例) メイン: https://www.youtube.com/watch?v=xxxx(さくらみこ) / 別視点: https://www.youtube.com/watch?v=yyyy(星街すいせい)
```

## ★ 5. ゲーム・企画ごとの用語
よく配信されるゲームの名前と、その中の固有の言葉(キャラ名・地名・アイテム名など)。
```
例) マインクラフト: ネザー・エンダードラゴン・匠
```

## ★ 6. チャンネル固有の言葉・口癖・定番の挨拶
```
例) さくらみこ: にぇ・みこち・35P(ファンの呼び名)
```

## ★ 7. 字幕の書き方の決まり
クラウドの文字起こしと比べるとき・正解データをそろえるときに必要です。当てはまる方を残してください。
- つなぎ言葉(「えっと」「あのー」): 残す / 消す
- 数字: 漢数字(三つ)/ 算用数字(3つ)/ 場合による
- 笑い: 「www」/「(笑)」/ 書かない
- 語尾の伸ばし(「そうだよー」「そうだよ～」): ー / ～ / 伸ばさない
- 英単語: カタカナ / 英字 / 場合による
