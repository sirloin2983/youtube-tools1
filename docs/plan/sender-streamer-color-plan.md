# 送るアプリ: 配信者をプルダウンで・人数分・字幕の色をカラーコードで(2026-10-05 Claude Code)

> **状態(2026-10-05): 設計だけ決めた。未実装**(ユーザー「まだ実装しない」)。実装はユーザーの指示のあと。元の設計は `docs/design/friend-intake.md`(2-4 話す人)。

## 1. 要望(ユーザー 2026-10-05)
- 友人側の送るアプリで、配信者名をプルダウンで入れたい
- 配信の URL で送るときも、配信者名を人数分入れられるようにする。入力が無ければ今までどおり
- ついでに、字幕の色をカラーコード(# なし)で指定できるようにする

## 2. 今(送るアプリ 2.0.0)
- 「話す人」(03): 人数の −/+ と人数分の名前の欄。URL・動画の両方。JSON の `speakers` {count, names} → PC は話者分離と名前付け
- 「配信者」: 動画のときだけの 1 つの欄。JSON の `streamer` → 字幕の色。URL のときは欄が無く、PC がチャンネル名から決める
- どちらも文字を打つ欄(`members.json` の名前が候補に出る)

## 3. 決めたこと(ユーザー 2026-10-05)
1. **「配信者」と「話す人」を 1 つにまとめる**。欄は「配信者」の 1 種類。URL でも動画でも人数分の行
2. **1 行 = 名前 + 色**。名前はプルダウン(選べる・一覧に無い名前も打てる)。色は 6 桁のカラーコード(# なし)。横にその色の見本
3. 色の決まり方: 色が空で名前がメンバー → メンバーカラー / 色が空で一覧に無い名前 → 今までどおり(色なし)/ 色を入れた → その色を優先(メンバーでも上書き)
4. 何も入れない → 今までどおり(話者分離なし・色はチャンネル名から)
5. **指定した色は、その文書にだけ覚える**(文書の話者に「字幕の色」を持たせ、「編集」の 3 パック でも見えて直せる)。PC の「自分の色」の一覧には登録しない(友人の入力で PC の設定を恒久的に書き換えない)
6. **名前なしで人数だけ指定する使い方は残す**(人数の −/+ はそのまま。名前と色は空でよい)

## 5. 注意(リスク)
- 色は外から来る文字 = 受け取る側で必ず 16 進 6 桁だけに検査する(画面・Lua に入るため)
- 名前は今までどおり長さと制御文字を検査。プルダウンでも打てるので、検査は減らさない
- 新しいアプリ + 古い PC / 古いアプリ + 新しい PC のどちらでも今までどおり動くこと(色のキーが無い・`streamer` だけ、を両方テストする)
- 色だけ入れて名前が空の行は、送る前にアプリで止める(どの話者の色か決まらない)
