# 送るアプリ: 配信者をプルダウンで・人数分・字幕の色をカラーコードで(2026-10-05 Claude Code)

> **状態(2026-10-05): 実装済み(送るアプリ 2.1.0・ホーム 0.34.0・編集 0.55.0・cut2resolve 0.21.0。実機の通し(本物の Dropbox・Resolve)は未確認)**。実装の記録は `docs/design/friend-intake.md` の 2-8。元の設計は `docs/design/friend-intake.md`(2-4 話す人)。

## 1. 要望(ユーザー 2026-10-05)
- 友人側の送るアプリで、配信者名をプルダウンで入れたい
- 配信の URL で送るときも、配信者名を人数分入れられるようにする。入力が無ければ今までどおり
- ついでに、字幕の色をカラーコード(# なし)で指定できるようにする

## 2. 今(送るアプリ 2.0.0)
- 「話す人」(03): 人数の −/+ と人数分の名前の欄。URL・動画の両方。JSON の `speakers` {count, names} → PC は話者分離と名前付け
- 「配信者」: 動画のときだけの 1 つの欄。JSON の `streamer` → 字幕の色。URL のときは欄が無く、PC がチャンネル名から決める
- どちらも文字を打つ欄(`members.json` の名前が候補に出る)

## 3. 決めたこと(ユーザー 2026-10-05)
1. **「配信者」と「話す人」を 1 つにまとめる**。欄は「配信者」の 1 種類。URL でも動画でも人数分の行
2. **1 行 = 名前 + 色**。名前はプルダウン(選べる・一覧に無い名前も打てる)。色は 6 桁のカラーコード(# なし)。横にその色の見本
3. 色の決まり方: 色が空で名前がメンバー → メンバーカラー / 色が空で一覧に無い名前 → 今までどおり(色なし)/ 色を入れた → その色を優先(メンバーでも上書き)
4. 何も入れない → 今までどおり(話者分離なし・色はチャンネル名から)
5. **指定した色は、その文書にだけ覚える**(文書の話者に「字幕の色」を持たせ、「編集」の 3 パック でも見えて直せる)。PC の「自分の色」の一覧には登録しない(友人の入力で PC の設定を恒久的に書き換えない)
6. **名前なしで人数だけ指定する使い方は残す**(人数の −/+ はそのまま。名前と色は空でよい)

## 4. 実装の見通し(まだやらない)
- 送るアプリ(`request-sender/`。C# 5・WinForms): 名前の欄を ComboBox(DropDown = 選べる・打てる。配色は今の `Field` に合わせる)・色の欄(16 進 6 桁だけ受ける。# を貼っても外す)と見本・動画の側の「配信者」の欄をやめる・
  JSON は `speakers` に色を足し(名前 → 色の対応。古い PC は知らないキーを読み飛ばす)、1 人目を `streamer` にも入れる。版 2.1.0・`build.bat` のテスト

## 5. 注意(リスク)
- 色は外から来る文字 = 受け取る側で必ず 16 進 6 桁だけに検査する(画面・Lua に入るため)
- 名前は今までどおり長さと制御文字を検査。プルダウンでも打てるので、検査は減らさない
- 新しいアプリ + 古い PC / 古いアプリ + 新しい PC のどちらでも今までどおり動くこと(色のキーが無い・`streamer` だけ、を両方テストする)
- 色だけ入れて名前が空の行は、送る前にアプリで止める(どの話者の色か決まらない)

## 6. 将来に備える形(ユーザー 2026-10-05「字幕のフォントやパラメータなどを将来指定される場合がある」)
今回作るのは色だけ。ただし、あとからフォント・大きさ・ふちなどを足しても形を変えずに済むよう、**色を単独の値で持たず「字幕の見た目」のまとまりの中の 1 項目にする**。
- **依頼の JSON**: `speakers` に人ごとのまとまりを足す = `"people": [{"name": "…", "style": {"color": "RRGGBB"}}]`(`names` は古い PC のために今までどおり書く)。
  あとで足すときは `style` に鍵を足すだけ(例: `font`・`size`・`outline`)。依頼全体の見た目(全員に共通)は、依頼の直下の `style` を予約する(今回は書かない)
- **文書**: 話者に `sub = {"color": "#RRGGBB"}`(字幕の見た目。画面の行の色 `color` とは別の項目)。あとで `sub` に鍵を足す
- **cut2resolve の API とパック**: 色だけの `speakerColors` を増やさず、`output.speakerStyles = {話者の名前: {"color": …}}` を足す。パックの中では今の `speaker_colors`(字幕ごとの文字の色 `fills`)へつなぐ。
  フォントなどを足すときは、同じまとまりから字幕ごとの値を作る(今の `speaker_outlines` と同じ道)
- **検査は鍵ごとの許可の一覧**(知っている鍵だけ受け、型と長さを確かめ、知らない鍵は捨てる。`sanitize_pack_output` と同じ考え方)。新しいアプリが古い PC に知らない鍵を送っても、色までは今までどおり効く
- 優先の順(あとで項目が増えても同じ): 人ごとの指定 → 依頼全体の指定 → メンバーカラーなど PC の決まり → PC の設定の既定
- **フォントを足すときの注意(今は決めない)**: フォントは友人の PC ではなく、パックを開く Resolve の PC に入っているものしか使えない。名前を自由に打たせず、PC 側が持つ一覧から選ぶ形にする(今のパックも、指定のフォントが無いときの代わりを持っている)
