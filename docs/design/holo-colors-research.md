# ホロカラー: メンバーの色の調べ方と記録
> 状態(2026-09-30): 手順は決定・全員(86 人・20 グループ)を調べて記録した(下の「記録」)。同じ日に早見表(非公式 wiki)と照らし合わせ、迷った候補の色を全員分 `colors` に足した(下の「早見表と照らし合わせ」。ユーザー決定)。計画は `docs/plan/phase7-holo-colors.md` の 7-2・7-3、members.json の形は `docs/design/holo-colors.md` の「メンバーの色」

## 目的
- `holo-colors/members.json` の色を、**決まった手順**で調べ、**色ごとに出どころと確かさ**を残す(あとから誰でも確かめ直せるように)
- 1人に複数の色(`colors`)を持てる。**主な色(`hex` = `colors[0]`)は今の色から変えない**のが既定(字幕の色が急に変わらないように。2026-09-29 ユーザー決定)。
  変えたほうがよさそうな人・出典で色合いが違う人は、両方を `colors` に入れて「ユーザーに聞くこと」に書く

## 出典の順位
1. **公式の明示** … 本人・カバーの公式アカウントの「メンバーカラー」の発言、公式グッズ・公式ライブのペンライトの色の案内、公式サイトのプロフィール
2. **ホロジュール**(https://schedule.hololive.tv/ 。カバー運営)の配信の枠のアイコンの縁の色。今のページと Wayback Machine の保存版
3. **公式サイトの画像から取った色**(hololive.hololivepro.com のタレントの画像。今は非公式 wiki の表 s4 の値を使う)
4. **非公式の wiki・まとめ**(s3・s5・s6・s7 など)… 照らし合わせだけ。**これだけでは採らない**

- **独立でない出典を2つと数えない**: s5 と s6 は同じ表(s6 は s5 の写し)、s3 はホロジュールの色を写した表(s1・s2 と独立ではない)、s4 は公式サイトの画像から wiki の人が取った色
- ホロジュールの色は「そのタレントが1人で配信している枠」で見る(コラボの枠は主催の色になるため)。2人共用の色(FUWAMOCO の #F9F1E4)は個人の色として主にしない

## 確かさ(`confidence`)
| 値 | 基準 |
| --- | --- |
| high | ①か②で色コードが直接取れた。②は今のページか、複数の保存版で同じ |
| medium | 画像から取った色(③)・①が色の名前だけ(例「水色」)で色コードを当てた・②が古い保存版1つだけ |
| low | ④だけ・出典どうしで食い違って決め手が無い |

## 決まり
- 画像から取るときは、縁や JPEG のにじみを避け、平らな部分の中央値を取る。取った場所を記録に書く。**画像そのものはリポジトリに入れない**(Public のため・著作物のため。URL と取得日だけ)
- ペンライトの色は名前で示されることが多い → `label` に名前(「ペンライト: 水色」)を書き、色コードは近いものを当てて medium
- 各出典は `sources` に URL・取得日(`retrieved`)・あれば Wayback の保存版(`archive`)を残す(ページが消えても確かめ直せるように)
- **取得できなかった出典は「確かめられなかった」と書き、推測で埋めない**(確かさを上げない)
- 名簿の差(新しいデビュー・卒業)に気づいたら下の「名簿の差」に書く。足すか・動かすかはユーザーに聞く(この段の目的は色)
- 1グループ書くごとに形の検査(`holo-colors\build.bat` の BundledMembers・`python -m unittest ytt_core/tests/test_ytt_core.py`)を通す。途中で止めても一覧が壊れない順に進める

## 1人の調べ方
1. ホロジュールの今のページで、その人が1人で配信している枠の縁の色を見る(出ていなければ Wayback の保存版)
2. 公式の明示(①)を探す(公式ショップのペンライト・本人のプロフィール・公式の発言)
3. 公式サイトの画像の色(③。s4 の値)と wiki(④)を照らし合わせる
4. 記録の表に1人1行: 採った色(主な色 / 2つ目以降)・採らなかった候補・出典・確かさ・理由
5. members.json: `colors`(主な色は今の `hex` のまま先頭)・`alt`(採らなかった候補)・`checked`(調べた日)を直す
