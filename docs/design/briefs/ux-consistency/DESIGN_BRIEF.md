## Problem

- **毎回同じことを入れさせられる。** 配信者の名前(字幕の色)は、画面に配信のチャンネル名が出ているのに空欄。パックのタブで入れても、同じ画面の「まとめて実行 ▾」には引き継がれない。予備・出力先・無音の設定・話者の人数・採用数も、開くたびに戻る。
- **同じ操作なのに、どこから押したかで結果が変わる。** 「まとめて実行」は 8 か所から呼べるが、パックの fps・縦横・話者の色のスイッチを無視する入口があり、上書きできる入口とできない入口がある。状態の言葉も「済み/済」「待ち/まだ」とばらばら。
- **話者の色が付いたり付かなかったりして、理由が分からない。** パック(Text+)には付くのに、パックの字幕の見本・カットのプレビュー・文字起こしの行には付かない。名前がメンバーと合わないと黙って配信者の色になる。
- **カットしないで出したいときの手段がない。** カットの無い文書は、自動で「行から」切られる。
- **キーを確かめる画面(?)で、そのまま変えられない。** 設定は別の場所(⚙ → キー配置)。スタジオでは共通の再生キーが変えられない。
- **終わったあとに次の一手が出ない。** 完了の知らせは 2.5 秒で消え、ボタンもない。「常に出す」つもりの知らせも消える(不具合)。何もしていないのに「完了」と出ることがある。

## Solution

「一度決めたことは、どこから操作しても同じに効き、二度と聞かない」画面にする。

- まとめて実行は、**どの入口でも同じ設定の欄**(1 つの部品)が出る。値は 1 か所に保存し、どこで変えても次から全部の入口の既定になる。パックのタブの fps・縦横・話者の色とも同じ値。
- 配信者の名前は、**配信のチャンネル名から自動で入り**(「自動: 兎田ぺこら(チャンネル名から)」と見える)、手で直したらそのチャンネル・配信・文書に覚える。
- 話者の名前がメンバーと合えば、**画面のどこでも同じ色**(文字起こしの行・映像の上の字幕・カットのプレビュー・パックの見本・パック)。合わないときは、話者の欄に理由を 1 行出す。
- カットのタブに「カットしない(動画全体)」。まとめて実行でもカットの方法(行から / カットしない / 無音)を選べる。
- **? で開くキーの一覧が、そのままキー配置の設定**になる。キーを押して割り当てを変える。編集とスタジオで同じ形。
- 何かが終わったら、**次の一手のボタンつきの知らせ**を出し、フォーカスを次に打つ所へ置く。

## Experience Principles

1. **聞くのは一度だけ** — 前回の値・チャンネル・文書から分かることは先に入れておき、入っている理由を見せる(「自動」「前回の値」)。自動で入れたものは、いつでも 1 手で直せる。
2. **入口は複数でも、中身は 1 つ** — 同じ操作は、同じ部品・同じ設定の値・同じ言葉・同じ結果。入口ごとの違いは「その場で決めること(対象・配信者・上書き)」の初期値だけ。
3. **結果と理由を必ず見せる** — 飛ばした・色が付かない・押せない・失敗したは、理由と次の一手をその場に出す。何もしなかったときは「完了」と言わない。

## Aesthetic Direction

`docs/design/briefs/ui-overhaul/DESIGN_BRIEF.md` のまま(落ち着いた仕事道具・明るいテーマ既定・強調色は意味にだけ・SVG の線のアイコン)。この見直しで新しい見た目は足さない。

- **Tone**: 静か・先回り。知らせは短く、ボタンは 1 つ(主)+ 閉じる。
- **Reference points**: Linear の「前回の値を覚えている作成フォーム」、DaVinci Resolve のキーボード設定(キーを押して割り当て・衝突をその場で表示)、VS Code のキーボードショートカット一覧(一覧 = 設定)。
- **Anti-references**: 入口ごとに違う小さなフォーム、確認ダイアログの連打、理由の無い灰色のボタン、読む前に消える知らせ。

## Key Interactions

### 1. 話者の色
1. 話者判別が終わる → 知らせ「話者を 3 人に分けました」[名前を付ける] → 話者の欄の最初の名前へフォーカス。
2. 名前を打つと候補(覚えた声・名簿)。「ぺこら」→ 兎田ぺこら の色の丸。行の左端の線・映像の上の字幕がすぐその色になる。
3. 合わない名前(「ゲスト」)→ 欄の下に「メンバーと合わないので配信者の色で出します」。ホームから開いていないとき →「ホームから開くと色を照らし合わせます」。
4. パックの見本・カットのプレビューも行ごとにその色。パックのタブの「話者の名前がメンバーと合えば…」のスイッチを切ると、全部の場所で消える(まとめて実行も)。

### 2. カットしない
- カットのタブ:「カットしない(動画全体)」を押す → 残す区間が 1 つ(動画全体)になり、行のカット済の印も外れた見え方(字幕は全部出る)。元に戻す(Ctrl+Z)で戻せる。
- まとめて実行: 設定の「カットの方法」= 行から(行の端の広げ方) / カットしない / 無音で削る(dB・長さ・前後の余白)。**カットを保存済みの文書は、そのカットのとおり**(今と同じ。設定で「保存済みのカットも作り直す」は選ばない限りしない)。

### 3. まとめて実行
1. どの入口でも、ボタンの横に要約 1 行と「設定を変える」。変えた値は保存され、次から全入口の既定。
2. 形(採用後を全部 / 文字起こしまで / 解析から全部)の初期値は、その配信の状態から選ぶ(マーク 0 なら「解析から全部」)。
3. 開始前に見積もり。やることが 0 なら「やることがありません(理由)」で始めない。
4. 設定: 形・採用数・カットの方法と細かい値・パックの出力(fps・縦横・話者の色・予備。パックのタブと同じ値)・上書き(パックがあれば作り直す。配信単位の実行でも選べる)・失敗したとき(次へ進む / 止める)。
5. 進み具合は同じ札と言葉(済み・待ち・実行中・失敗・飛ばした)。終わったら知らせ「4 本のパックができました」[校正を始める]/「1 本失敗しました(理由)」[やり直す]。何もしなかったら「完了」と言わない。
6. 配信者は自動で入る(上の Component の順)。行の「この後を ▸」も、実行前に「字幕の色: ○○」をその行に出す。

### 4. ? でキーを変える
1. ? → キーの一覧(共通の再生キー / このツールのキー / 変えられないキー(錠と理由))。
2. キーのボタンを押す →「次に押すキーを割り当てます(Esc で取り消し・Delete で外す)」→ キーを押す → その場で反映。キーの帯・ボタンの横のキー・ツールチップ・知らせの文も同じ割り当てで出す(今は一部が固定の文字)。
3. 衝突 → 一覧の中に「Shift+← は「3 秒戻る」から外しました」[戻す]。Esc は取り消しだけで、一覧は閉じない。
4. ⚙ 設定の「キー配置」は同じ部品を出す(場所が 2 つでも中身は 1 つ)。

### 5. 毎回同じ入力をなくす(覚えるもの)
| 値 | 覚える単位 | 今 |
| --- | --- | --- |
| 配信者(字幕の色) | 文書・配信 > チャンネル > チャンネル名から自動 | パックのタブだけ文書ごと |
| まとめて実行の形・採用数・カットの方法・上書き・失敗したとき | 全体(1 か所) | ホームだけ・このブラウザだけ |
| パックの予備・粗編集の動画・出力先 | 全体(出力先は前回のパックの場所) | 毎回戻る |
| 無音で削るの値 | 全体 | 毎回戻る |
| 話者の人数 | 文書(初期値 = その文書の話者の数) | 全文書で共通 |
| 前回開いていた文書とタブ | 全体 | 戻らない |
| スタジオ ③ の再生位置・選んだマーク | 配信 | 毎回 0:00 |

「このブラウザだけ」に保存していた値のうち、窓とブラウザで変わると困るもの(形・採用数・話者の色のスイッチ・配信者・書き出しの後の自動文字起こし)はサーバーに移す。見た目の好み(文字の大きさなど)はブラウザのまま。

### 6. 使いごこちの見直し(調査の結果から。実装の一覧は付録)
- 終わったら次の一手: 文字起こし完了 [開く]・話者判別 [名前を付ける]・校正がすべて済んだ [カットへ]・パック完了 [フォルダを開く](フォーカスもそこへ)・書き出し完了 [編集で開く]。
- 同じ動画を 2 回文字起こししようとしたら「前に作った文書があります」[開く][作り直す]。
- パックの作り直し: 同じ場所への作り直しは確認を省き、ボタンを「作り直す(上書き)」に。札に「何が変わったから作り直しが要るか」。動画のコピーは同じなら飛ばす。
- 理由を言わない無効をなくす: ホームから開かないと使えない機能は、隠さず押せない理由を出す。
- 設定の保存に失敗したら見せる(今は黙って捨てている)。
- 押せない札(「次: カット」「→ 書き出し 2 本」)は押せるボタンにして、その作業へ直接移す。
- ホームの「次にやること」に、書き出し待ち・文字起こし待ち・確認前の候補も出す。
- 用語をそろえる(「入口」→「ホーム」、「Resolve パック」/「パック」、「削る/戻す」と「カット済/残す」)。

## Responsive Behavior

作業の画面は PC の窓(Edge のアプリの窓)が前提。幅 960px 以上で崩れないこと(今の決まり)。まとめて実行の設定の欄は、狭い所(スタジオ ① のカード・ホームの行)では要約 1 行 + 「設定を変える」でポップオーバー(幅 360px 前後・縦にスクロール)。キーの一覧は 2 列 → 幅 960px 未満で 1 列。

## Accessibility Requirements

- 知らせのボタン・キーの一覧のキーのボタンは、キーボードだけで操作できる(Tab で届く・Enter/Space で押せる)。キーを待っている状態は `aria-live` で読み上げる。
- 色だけで意味を伝えない: 話者の色の丸の横に名前、「自動」「前回」は文字の札。メンバーカラーの字幕は白いふち・黒いふち(今の見た目)で背景に関係なく読めるので変えない。文字起こしの行の文字色は変えない(明るいメンバーカラーは白い背景で読めないため。色は左端の線と話者の欄だけ)。
- フォーカス: 完了の知らせのあとは次に打つ所へ。押したボタンが無効になるときは、中止ボタンなど次の操作へ移す(フォーカスを失わない)。
- 文字と背景のコントラスト 4.5:1 以上(札・ヒントの灰色の文字も)。

## Out of Scope

- 認識の精度(声の検出を pyannote に替える案など)・Holodex 連携・リアルタイム切り抜き。
- 見た目の作り替え(色・文字・レイアウトの方針は 09-27 のまま)。
- SRT への色(ユーザーは今回選んでいない)。話者1 などメンバーと合わない話者のメンバーカラー化(自動の色のまま)。
- 動画を選び直す機能(ファイルの移動・改名で参照が切れたとき。既知の未対応。付録の G-19)。
- ホロカラー(Windows の常駐アプリ)。

## 決めたこと(2026-09-29 のユーザーの答え)

- 話者の色: 「色が出ていない所がある」(→ 見本・プレビューが原因の候補)+ 文字起こしの画面でも。画面の色は**話者の色(左端の線・話者の欄)をメンバーカラーに**、文字の色は変えない
- カットしない: カットのタブとまとめて実行の両方。カット済の行の**字幕も全部出す**
- まとめて実行: **どの入口にも全部の設定**(方法は任せる)→ 1 つの部品・値は 1 か所。ある入口で変えたら**全部の入口の既定も変わる**。細かく選ぶのは**カットの方法**と**順番と上書き**。失敗したときは**設定で選べる**
- 配信者: **配信のチャンネルから自動 + 覚える**(2026-09-27 の「自動では入れない」を、今回のユーザーの答えで変更)
- キー: **? の一覧でそのまま変える**(スタジオもそろえる)
- 見直し: **全部まとめて今回やる**。進め方は ui-dev-workflow を全部
