# RS8 の画面の問答(案件を中心にした画面 + 確かめる)

前提は `plan/rs8-cases-ui.md`(決めたこと 1〜5)と下調べ `inventory.md`。

## 決めたこと
1. **作業の進め方 = どちらにも対応**(おすすめのとおり): 入口に**作業の待ち行列**(採用待ち・校正待ち・パック待ちなど。今のホームの「次にやること」を育てる)を置き、押すとその案件のその作業の所へ直接飛ぶ / 案件の画面は 1 本を通して進める作り。待ち行列は「確かめる」と同じ形のリスト(作りを共用)
2. **案件の画面 = 左に切り抜きの一覧・右に作業のタブ・同じ窓で完結**: 左の一番上が「候補(配信全体)」、その下に切り抜きが 1 本 1 行(状態 = 未・校正中・校正済み・パック済み)・[+ 切り抜きを足す]。右のタブは切り抜きを選ぶと [校正] [カット・パック]、候補を選ぶと [候補](プレーヤー + タイムライン + マークの一覧)。1 本済んだら次の未校正へ進むボタンとキー。上に「この案件で確かめると効く物 n 件」。窓の行き来(今はツールをまたぐのが 3 回)を無くす
3. **校正のタブの中に配信のプレーヤーを小さく出せる**(今の「配信を見ながら隣の窓で校正する」= 決定 (ad) の代わり)
4. **入口(ホーム)の並び = 仮決定**(ユーザー「これで仮決定。使ってみて改善していく」): 上から LIVE の帯(録画中だけ)/ **やること**(作業の種類ごとの件数 = 採用待ち・校正待ち・パック待ち・失敗。押すといちばん古い 1 件のその作業の所へ・案件の画面の「次へ」で同じ種類の次へ続ける)と **確かめる**(今いちばん効く確認を 1 つ + 「あと何本で何が決まるか」+ [始める])を横に並べる / **案件の一覧**(状態とメモ・**[+ 新しい案件(URL・探す)]** = 今のスタジオ ① をここへ寄せる・検索)/ **運用**(依頼の受付・バックアップ・まとめて実行の記録・調子)は下に畳む
   - **「続けて確認」(A5。自動の切り抜きを 1 本ずつ見て 採用 = 友人へ届ける / 要らない)を「確かめる」の 1 枚のカードに入れ、V1 の「70 点以上か」と同じ判断として数える**(ユーザーの基準 = 70 点以上を友人へ送る → 採用 = 70 点以上・要らない = 未満)= V1 の 7 番目は今の採用 / 要らないの記録を数えるだけで済む
5. **確かめるの順 = 目標まであと少しの物 → 軽い物**。期限(3 日で片付く自動の切り抜き)は順に入れない(ユーザー「期限のある物は別にどうでもいい。必要なら新しく取ればいい」)。その他(カードの流れ・定点の目標をそろえる)は AI に任せる(ユーザー「その他は任せる」)→ `DESIGN_BRIEF.md` の「AI が決めたこと」
6. **軽いカードは 4 種類**(10-11。見本を見たあと): 切り抜く価値(自動で採った / 候補のまま)・どちらの読み(後処理 / 別のエンジン。文字だけの判定 = 時刻の正解にしない)・これは誰の声?(全部に機械の予想・直接答えた行だけ覚える・まとまりで名前を付けない・測るのは評価用のまま)・行の時刻(前後 2〜3 秒の余分・文字が正しい行だけ)。詳しくは `DESIGN_BRIEF.md` の 2-3
