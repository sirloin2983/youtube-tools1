切り抜き依頼 かんたんガイド

はじめに

このアプリは、切り抜いてほしい配信の URL を入れて「送る」を押すだけのアプリです。あとはパソコンが配信を見て、盛り上がった所を選び、字幕つきの編集用ファイル(DaVinci Resolve で開けるもの)まで作ります。

流れはこの 3 つだけです。

  1. 配信の URL を入れて「送る」
  2. できあがると、数本まとめた「組」とまとめ動画が届く
  3. まとめ動画を見て、1 本ずつ「受け取る」か「要らない」を選ぶ。受け取った物を Resolve で仕上げる
配信の細かい確認や、字幕を直す作業は、このアプリではしません。仕上げは Resolve だけです。

初回の準備

1. 「スマート アプリ コントロール」をオフにする

これを先にやっておかないと、文字起こしの部品が Windows に止められて「処理が途中で止まりました」になります。
  1. Windows の「設定」を開く
  2. 「プライバシーとセキュリティ」→「Windows セキュリティ」→「アプリとブラウザー コントロール」
  3. 「スマート アプリ コントロール」を開き、「オフ」を選ぶ

一度オフにすると、Windows を入れ直さない限り戻せません。すでに「オフ」になっているなら、そのままで大丈夫です。

(画像の予定: スマート アプリ コントロールの設定画面)

2. 初回の取得(約 9GB)

最初にアプリを開くと、文字起こしなどに使う部品とデータを自動で取ってきます。合計で約 9GB あるので、次のことを守ってください。

  • インターネットにつないだまま、PC をスリープさせない(進み具合が窓に出ます)
  • 空き容量を 20GB ほど確保しておく
  • 途中で窓を閉じても大丈夫です。次に開くと続きから取ります

「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します(最初の 1 回だけ)。

このとき、パソコンのグラフィックボードの種類も自動で調べます。何も操作は要りません。

YouTube の API キーの取り方

API キーは「コメントも見どころの判断に使う」ための物です。なくてもアプリは動きます(コメントを使わないだけです)。後回しにして大丈夫です。

キーは Google の無料の仕組みで自分で作ります。クレジットカードは要りません。10〜15 分ほどです。

手順 1. プロジェクトを作る

  1. プロジェクトの作成ページを開く(Google にログインします)
  2. プロジェクト名は何でもよいです(例: kirinuki)。「作成」を押す
  3. 利用規約の確認が出たら、内容を読んで同意します
(画像の予定: プロジェクトの作成画面)

手順 2. YouTube Data API v3 を有効にする

  1. YouTube Data API v3 のページを開く
  2. 上のプロジェクト名が、さっき作った物になっているか確かめる
  3. 「有効にする」を押す
(画像の予定: 「有効にする」ボタン)

手順 3. キーを作る

  1. 認証情報のページを開く
  2. 「認証情報を作成」→「API キー」を選ぶ
  3. キーが表示されます。「キーを制限」を押して次の手順へ(この画面は閉じずに)
(画像の予定: 「認証情報を作成」のメニュー)

手順 4. キーを「YouTube Data API だけ」に絞る

もしキーが他人に見えてしまっても悪用されにくいよう、使える範囲を狭くします。

  1. 「API の制限」で「キーを制限」を選ぶ
  2. 一覧から「YouTube Data API v3」だけにチェックを入れる
  3. 「保存」を押す
(画像の予定: API の制限の設定)

手順 5. アプリに貼る

  1. 作ったキー(英数字の長い文字列)をコピーする
  2. アプリの「設定」を開き、「YouTube の API キー」の欄に貼る
  3. 貼ると、アプリがその場で 1 回確かめて、「使えます」か、使えない理由を表示します
キーは人に見せたり、SNS やチャットに貼ったりしないでください。このアプリのキーは、あなたの PC の中にだけ保存されます(送った依頼には入りません)。

つまずきやすい所

  • 「API が有効になっていません」と出る: 手順 2 を、キーを作ったのと同じプロジェクトでやったか確かめる。有効にした直後は数分かかることがあります
  • 「キーが違います」と出る: 貼るときに前後の空白や、一部の取りこぼしがないか。もう一度コピーし直す
  • 「制限されています」と出る: 手順 4 で「YouTube Data API v3」にチェックが入っているか確かめる
  • どうしても詰まる: 無理せず、教えてくれた人に伝えてください(画面共有で一緒に見られます)。キーなしでも使えます

使い方

送る

  1. アプリの上の「送る」を開く
  2. YouTube の配信の URL を欄に貼る。題名が下に出るので、貼り間違いがないか確かめる(何本か続けて貼ってもよいです)
  3. 「切り抜く数」を決める(1〜10)。ここで決めた本数を、パソコンが自動で選びます
  4. 下の「送る」を押す。「送りました ✓」が出れば完了です

切り抜いてほしい時刻が決まっているなら、「区間」の欄に開始と終了を入れられます(入れなくても大丈夫です)。配信の最中なら「ライブ配信」の欄に URL を入れると、配信を見ながら自動で切り抜きます。動画のファイルを送りたいときは、「動画ファイル」の欄にドラッグします。

「届け方」を「n 本ごと」にすると、n 本たまるたびにまとめて届きます(例: 5 本ごと)。

まとめ動画を見る

できあがると、上の「受け取る」に数字が出ます。開くと一覧が出るので、「まとめ動画を見る」を押してください。選んだ切り抜きを小さい動画につなげた物が、アプリの窓で再生されます(字幕はまだ入っていません)。

受け取る / 要らない / 動画にした

見て、1 本ずつ次のどれかを選びます。

  • 受け取る: 欲しい切り抜きです。パソコンにフォルダとして保存されます(初期の保存先は「ダウンロード\切り抜き依頼」)。Resolve で開いて仕上げます
  • 要らない: 外れの切り抜きです。受け取らずに消します。外れだったことは自動で伝わり、次回からの選び方の改善に使われます。迷ったら「要らない」で大丈夫です
  • 動画にした: 受け取ったあと、実際に動画に仕上げて公開した物に押します。押すと「こういう切り抜きが当たりだった」という手がかりとして伝わります。押し忘れても困りません

受け取る・要らないのどちらも、あとから取り消せません。迷ったら先にまとめ動画を見てください。組の行をまとめて選ぶと、残りを一度に受け取る・要らないにもできます。

窓を閉じるとき

アプリはずっと動かしておく必要はありません(常駐しません)。切り抜きの処理中や録画中に × を押すと、3 つから選べます。

  • 終わったら閉じる(おすすめ): 窓は小さくなってタスクバーに残り、全部の依頼が終わると自動で閉じます
  • 今すぐ止めて閉じる: すぐ止まります。次に開いたとき、続きから再開します
  • やめる: 閉じずにそのまま続けます
配信を録画している最中にアプリを完全に止めると、止めた間の配信は録画できません。ライブ配信の依頼は、配信が終わって処理が済むまで、アプリを開いたままにしてください。

処理する PC の切り替え

切り抜きの処理は、ふつうはあなたの PCで行います。ほかに、教えてくれた人の PC に頼むこともできます。同時に何本も配信を切り抜きたいときに便利です。

  • 送る画面の「処理する PC」で選びます(依頼ごとに選べます)
  • はじめは「自分の PC」です
  • 自分の PC で別の依頼が動いている間は、「相手の PC に頼む」を選ぶと、そちらで同時に進められます
  • どちらを選んでも、届く物と受け取り方は同じです

相手の PC に頼んだ分は、相手の PC が動いているときだけ進みます。あまり遅いときは、教えてくれた人に聞いてみてください。

送り返している物

アプリは、よくなるための手がかりとして、次の 3 つを自動で教えてくれた人の Dropbox に送り返します。操作は要りません。動画そのものは送りません。

  1. 「要らない」「受け取る」「動画にした」の答え
  2. 処理の記録(文字起こしの文章・どこを候補にしたか・点数など。1 本あたり数 MB)
  3. 調子の記録(エラーが出たときの記録)

YouTube の API キーや、あなたのパスワードに当たる物は送りません。

うまくいかないとき

処理が途中で止まりました、と出る

まず「スマート アプリ コントロール」がオフになっているか確かめてください。それでも直らないときは、一度アプリを閉じて開き直すと、続きから再開します。

「Windows によって PC が保護されました」と出る

「詳細情報」→「実行」を押します。署名のないアプリに出る確認で、最初の 1 回だけです。

初回の取得が止まった・遅い

インターネットにつながっているか、空き容量があるか(20GB ほど)を確かめ、アプリを開き直してください。続きから取ります。

空き容量が足りない、と出る

PC の動作を守るため、空きが少ないと新しい処理を始めません。いらないファイル(受け取り済みの動画など)を移すか消して、空きを作ってください。

まだ何も届かない

配信の長さによっては、何時間もかかります。「受け取る」の「更新」を押して、しばらく待ってください。アプリを開いている間は、3 分ごとに自動で確かめます。

API キーの確認で「使えません」と出る

API キーのつまずきやすい所を見てください。キーなしでも切り抜きはできます。

それでも直らない

画面のメッセージをそのまま(スマホで撮った写真でも)教えてくれた人に伝えてください。画面共有でいっしょに見ることもできます。
