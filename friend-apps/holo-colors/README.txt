==========================================================
  ホロカラー(HoloColors) v1.4.1
==========================================================
ホロライブのメンバーカラーを一覧から選んで、カラーコードをコピーする Windows のアプリです。
どのアプリを使っているときでも、キー(はじめは Ctrl + Alt + H)で一覧が開きます。
インターネットにはつながりません。インストールも要りません(Windows 10 / 11 にはじめから入っている .NET Framework で動きます)。

【はじめに(最初に1回)】
  1. 受け取った HoloColors.zip を右クリック →「すべて展開」。できた HoloColors フォルダを、消さない場所(例: ドキュメント)に置く
     (HoloColors.exe と members.json は、同じフォルダに入れたままにしてください)
  2. HoloColors.exe をダブルクリック
     「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
     (インターネットで受け取った、署名の無いアプリに出る確認です。最初の1回だけ)
  3. 一覧が開き、タスクバーと画面右下の通知領域(時計の横。見えなければ ^ の中)に4色のアイコンが出ます。これで待機中です
     タスクバーのアイコンを右クリック →「タスクバーにピン留めする」にしておくと、次からそこから起動でき、動いている間はアイコンの下に印が付きます
  4. 毎回ダブルクリックするのが面倒なら: 一覧の「設定」→「Windows にサインインしたら裏で起動しておく」にチェック

【使い方】
  - Ctrl + Alt + H で一覧を開く(タスクバーのアイコンを押しても開く)。もう一度押す・Esc で閉じる
    (閉じると最小化されてタスクバーに残り、アプリは待機しています)。
  - 右上の × はアプリの終了です(Ctrl + Alt + H も効かなくなります。また使うときはタスクバーのアイコンから起動)。
    検索の文字が入っているときの Esc は、まず文字を消します(もう一度 Esc で閉じる)
  - 札の上段は名前、下段はその人の色の帯です(色の数だけ同じ幅に分け、多いときは2段・3段に折り返します)。
    帯を押す → その色のカラーコード(例: FF6699)がコピーされ、一覧が閉じて、前に使っていたアプリに戻ります(名前の段・Enter は主な色)。
    そのまま Ctrl + V で貼り付けられます(マウスの横に「〜をコピーしました」と少しだけ出ます)
  - 探す: 開いてすぐ文字を打つと絞り込めます。名前(ひらがな・カタカナどちらでも)・ローマ字・カラーコード・「3期生」など。
    ↑ ↓ ← → で選んで Enter でもコピーできます
  - 上の札で絞り込み: すべて / マイカラー / マイワード / JP / DEV_IS / EN / ID / 卒業
  - お気に入り: 札の右上の ☆ を押す(または右クリック →「お気に入りに入れる」)と、「すべて」のいちばん上の「お気に入り」に並びます。
    その下の「最近使ったもの」には、直近にコピーした 5 つが並びます。どちらも写しで、元のグループにもそのまま残ります
  - 札にマウスを乗せると、ローマ字の名前とグループ(色が2つ以上ある人は全部の色とその出どころ)が出ます
  - 右クリックのメニューにも色ごとの「コピー」があります

【自分の色を足す(マイカラー)】
  - 下の「＋ 追加」→「色を追加」→ 名前とカラーコード(#FF6699 の形。「色を選ぶ…」で色の画面から選んでもよい)→「保存」
  - 札を右クリック →「編集…」「前へ」「後ろへ」「削除」
  - 並べ替え: 札をつかんで(ドラッグして)動かす。または札を選んで Alt + ↑ ↓ ← →
  - メンバーの札を右クリック →「この人に色を追加…」で、その人に自分の色を足せます(札の帯が1本増えます)

【よく使う言葉を登録する(マイワード)】
  - 下の「＋ 追加」→「ワードを追加」→ 表示名(札に出す名前。空なら本文の1行目)と本文(何行でも。4000 文字まで)→「保存」(Ctrl + Enter)
  - 札を押すと本文がコピーされます(改行もそのまま)。並べ替え・編集・削除はマイカラーと同じ
  - メンバーの札を右クリック →「この色をもとにマイカラーへ追加…」(少し違う色を使いたいとき)

【メンバーの色を直す】
  - メンバーの札を右クリック →「色を直す…」。色を足す・消す・並べ替える・ラベル(12 文字まで)を付けられます
    いちばん上が主な色(札を押したとき・Enter でコピーする色)。「上へ(主にする)」で入れ替えます
  - 直した札は名前の前に「✎」の印が付きます。「色を直す…」→「元の色に戻す」で同梱の色に戻ります
  - 直した色は作業データのフォルダの member-colors.json に残ります(アプリや members.json を新しい版に入れ替えても消えません)
  - 同じ PC で youtube-tools の「編集」を使っているときは、主な色が字幕の文字の色にもなります

【設定(一覧の「設定」、または通知領域のアイコンを右クリック →「設定…」)】
  - 呼び出すキー: 欄をクリックして、使いたい組み合わせを押す(Ctrl・Alt・Win のどれかと一緒に)。
    他のアプリが使っている組み合わせや、Windows・ほかのアプリでいつも使う組み合わせ(Alt+F4・Ctrl+C・Ctrl+V など)は使えません(赤い字で知らせます)
  - コピーしたら窓を閉じる: 外すと、コピーしても一覧が開いたまま(続けて何色も使うとき)。一覧の下のチェックと同じです
  - 先頭に # を付けてコピーする: 外すと FF6699 の形でコピーします
  - 一覧をいつも一番手前に表示する: 付けると、ほかのアプリを押しても一覧が上に残ります(はじめは外してあり、キーで呼んだときだけ前に出ます)
  - Windows にサインインしたら裏で起動しておく
  - アプリを終了(通知領域のアイコンを右クリック →「終了」でも同じ)

【困ったとき】
  - キーを押しても開かない: タスクバーにアイコンがあって、下に起動中の印が付いているか見る(無ければ HoloColors.exe を起動)。
    アイコンにマウスを乗せて「キーが未登録」と出るなら、ほかのアプリと同じキーです → 設定で別のキーに
  - 色が違う: 札を右クリック →「色を直す…」。メンバーがいない: マイカラーに足してください(同梱の色については下の【メンバーの色について】)
  - 自分で足した色・直した色と設定は %LOCALAPPDATA%\youtube-tools\holo-colors\ にあります(設定の「作業データのフォルダを開く」)。
    新しい版に入れ替えても消えません
  - 新しい版に入れ替える: 通知領域のアイコンを右クリック →「終了」→ HoloColors フォルダの中身を新しいものに置き換える → 起動
  - やめる: 設定で「サインインしたら裏で起動」を外す → 終了 → HoloColors フォルダを消す
    (自分で足した色も要らなければ、上の作業データのフォルダも消す)

【メンバーの色について】
  同梱の色は members.json にあります(設定の画面に何人・いつ時点かが出ます)。
  公式のサイト・本人の発言・ファンのまとめを照らし合わせて選んだもので、公式の一覧ではありません。
  色ごとの出どころ(ホロジュール・公式サイトの画像など)と確かさも members.json に書いてあります。
  2つ目以降の色には、ファンの wiki(ホロライブ非公式 wiki の「早見表」)にある候補も入れてあります
  (公式サイトの画像の色(濃い部分・縁))。
  いちばん上の主な色は今までと同じです。
  違っていたら教えてください(札を右クリック →「色を直す…」で、すぐに自分の PC の色を直せます)。

【開発向け(このリポジトリで作る人へ。場所は friend-apps\holo-colors\。python のコマンドはリポジトリ直下で流す)】
  - 作る: build.bat をダブルクリック(Windows に入っている .NET Framework 4 の C# コンパイラを使う。追加のインストールは要らない)
      build\HoloColors.exe    アプリ(動いていれば、先に終了させてから作り直す)
      build\HoloColorsTests.exe  テスト 21 件(build.bat が流す。失敗したら dist は作らない)
      dist\HoloColors.zip     友人に送るもの(HoloColors.exe・members.json・この README.txt)
  - 通しの確認: python friend-apps\holo-colors\tests\e2e_holo_colors.py(本物のキー入力とクリックを送る。流す間はマウスとキーボードに触らない)
  - ソース: src\(C# 5 で書く。$"" ・ ?. ・ => のメンバーは使えない)。設計と決めたこと: docs\design\holo-colors.md
  - メンバーの色を直す: members.json を直して build.bat → dist の zip を送り直す(形と調べ方: docs\design\holo-colors.md・holo-colors-research.md)。
    友人の側は members.json を差し替えて、アプリを終了 → 起動し直すだけでも反映されます(exe の作り直しは要らない)
  - アイコンの絵を変える: python friend-apps\holo-colors\make_icon.py(src\app.ico を作り直す)
