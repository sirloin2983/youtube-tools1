使い方

配信の URL や動画を送ると、この PC で切り抜きを作り、受信箱に届けるアプリの説明です。 ボタンの名前は [送る] のように書いています。

  1. 送る
  2. 届く・受け取る
  3. ⚙ 設定
  4. 初回の準備
  5. 閉じるとき

1. 送る

上の欄に配信の URL を貼って、[送る] を押します。作り終わると、下の受信箱に届きます。 続けて別の URL を貼れば、次の行に並びます。一度に送るのは 1 本です。

パソコンの動画で送るときは、[動画ファイルを選ぶ] を押して動画を選びます。 URL の欄の代わりに動画の名前が出ます。[やめる] を押すと、URL の欄に戻ります。

送る欄の設定

  • 区間: 切り抜く所を時刻で決めます。書かなくても使えます。[+ 区間] で足します。 区間を入れると、その区間だけを切ります。区間の数が本数になるので、本数の欄は消えます。
  • 本数: 区間が無いときに、見どころを自動で探して切る本数です(1〜30)。 前に送ったときの値を覚えています。
  • 配信者: 名前は自動で入ります。違うときは直せます。 コラボのときは [+ 人] を押して、相手の名前を足します。
  • 詳しく: 押すと、細かい設定が出ます。普段は開かなくても使えます。 映像トラック・処理する PC・届け方・解析の重みが入っています。
  • 処理する PC: [この PC] は今使っている PC で作ります。 [ユーザーの PC] は作る人の PC に頼みます。結果は同じ受信箱に届きます。 ユーザーの PC に頼むと、ボタンの名前が [送る(ユーザーの PC へ)] になります。
  • 届け方: 5 本ずつまとめて届けるか、1 本ずつ届けるかを選びます。 5 本ずつのときは、まとめ動画で一度に見て選べます。

ライブ

配信中か、これから始まる配信の URL を貼ると、送る欄の下に設定が出ます。 ボタンの名前は [録画を頼む] になります。録画しながら切り抜きます。

  • 感度: 高いほど、小さな盛り上がりも拾います。
  • 1 時間の枠: 1 時間の配信から切る本数の上限です(1〜30)。
  • 長さ: 1 本の長さの秒数です。
  • 待ち: 候補が出てから、自動で切るまでの分数です(1〜60)。
  • 余白: 切る前後に足す秒数です(0〜5)。
  • 配信後: 配信が終わったあと、アーカイブからも切り抜きを足します。

2. 届く・受け取る

送った依頼は、次の順に進みます。

  1. 送った: 受け付けた状態です。順番を待っています。
  2. 作っている: 切り抜きと字幕を作っています。ライブは「録画中」になります。
  3. 届いた: 作り終わりました。ここで決めます。

作れなかったときは、行が「失敗」になり、理由が出ます。

組とまとめ動画

届いた物は、届け方で決めた本数ごとに「組」になります。組ごとにまとめ動画があり、 続けて見て選べます。組の中で、見たい切り抜きから再生できます。

決める

  • [受け取る] を押すと、受け取るの保存先へ移します。
  • [要らない] を押すと、一時保管の「ごみ箱」へ移します。ごみ箱の物は 3 日で消えます。
  • 何本か選んでから、[選んだ物を受け取る] か [選んだ物を要らない] を押すと、まとめて決められます。
  • 届いてから 3 日決めないと、自動で要らないになります。

札(ふだ)の意味

  • 依頼なし: ユーザーの PC が、自分の配信から自動で届けた物です。頼んだ覚えはありません。
  • ユーザーの PC: ユーザーの PC で作っている(作った)依頼です。

失敗の行

失敗の行には理由が出ます。[もう一度送る] を押すと、同じ依頼を送り直します。 [消す] を押すと、行を消せます。

3. ⚙ 設定

画面の ⚙ を押すと、設定が開きます。

  • 受け取るの保存先: [受け取る] を押した切り抜きを置く場所です。
  • 一時保管: 作っている途中の物を置く場所です。
  • 文字起こしのエンジン: A か C から選びます。
  • YouTube の API キー: 配信のコメントに書かれたタイムスタンプを、見どころを探す手がかりに使います。無くても動きます(コメントを使わないだけ)。
  • 空き容量の下限: 空きがこの GB 数より少なくなると、新しい処理を始めずに待ちます。
  • カットの既定: 切り抜きの前後を切るかどうかの初めの値です。初めは「しない」です。

4. 初回の準備

初めて開くとき、約 9.5 GB の部品を取ります。始める前に、中身・大きさ・置き場所・空き容量を見せて、確認を 1 回だけ出します。

  • 置き場所: アプリのフォルダの中に入ります。
  • 空き: 空きが足りないときは、取り始める前に止まります。空きを増やしてから、もう一度始めてください。
  • [あとで]: 今は取らずに進みます。ただし部品がそろうまで、[送る] は押せません。 上の帯の [取ってくる] を押すと、いつでも取り始められます。
  • 古い部品: C: の前のアプリの部品と同じ物があれば、写して使います。ネットから取り直さずに済みます。

5. 閉じるとき

窓を閉じても、作っている物と録画は続きます。

  • 作業が終われば、アプリは自分で終わります。
  • 作業が残っているときは、タスクバーに小さな状態の窓が出ます。 録画中・作っている・待っている数が見えます。
  • 状態の窓の [窓を開く] を押すと、受信箱をもう一度開けます。
  • 状態の窓の × は、録画中なら最小化になります。録画が無いときは、× で止めて閉じます。

止めたいとき

  • 状態の窓の [今すぐ止めて閉じる] を押します。
  • 受信箱の右上の [すべて止めて終了] を押します。
  • タスクバーのボタンにマウスを乗せると出る小さな見本の [止める] を押します。

どの方法も、確認は出ずにすぐ止まります。待っている依頼は消えずに残ります。 次に開くと、続きからになります。
