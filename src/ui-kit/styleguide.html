v10: 版の帯(UIKit.restart)

ホームから開いた画面(合言葉あり)だけ「起動し直す」が出る。単体で開いた見本では案内の文だけ。押すと入口の api/ytt/restart-self → api/ping が戻ったら読み込み直す。

v11: 時刻の欄(UIKit.timebox)

「:」を打たない。時 → 分 → 秒 の順に数字だけ
長さ —

欄を選んで 12345 → 1:23:45。← → で 時・分・秒 を選び、↑ ↓ で ±1(Shift で ±10)。BackSpace = 選んだ所を 0・Delete = 空に・Ctrl+V = 1:23:45 / 83:45 / 1h23m45s (「YouTube の URL も」の欄だけ、…?t=5025 の URL も読む)。

v16: 録画中の札(UIKit.liveBadge)
