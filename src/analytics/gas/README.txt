Youtube分析 連携(Google Apps Script)の設定手順

状態(2026-10-09): 新規。Code.gs の中身を Apps Script に貼って使います。

■ これは何か
PC のツール(http://localhost:8700/analytics/)が YouTube チャンネルの日次分析をして LINE に送るための、Google 側の窓口です。
PC は iPhone から直接データを受け取れないので、Google Drive を間に挟みます。

  iPhone のブックマーク「日次取得」 -> 既存の「Youtube日次」プロジェクトが Drive の raw/<日付>.json に書く(そのまま使う)
  -> このプロジェクト(Youtube分析 連携)が raw をツールに渡す
  -> ツールが作ったレポートをこのプロジェクトが受け取り、Drive の reports/ に保存して LINE に送る
  -> タップ忘れ・PC が動いていないときは、このプロジェクトが LINE で知らせる(1 時間ごとの見張り)

ツールは Google のログインなしで HTTPS で呼ぶので、すべての操作に合言葉(ANALYTICS_SECRET)が要ります。
合言葉と LINE の鍵はスクリプト プロパティにだけ置き、コードには書きません(ログにも出しません)。

■ 手順

1) 新しいプロジェクトを作る
   - https://script.google.com/ を開く(Drive と同じ Google アカウントで)
   - 左上の「新しいプロジェクト」を押す
   - 左上の「無題のプロジェクト」をクリックして、名前を「Youtube分析 連携」にする

2) コードを貼る
   - 左のファイル一覧の「Code.gs」を開き、最初から入っている中身を全部消す
   - このフォルダの Code.gs の中身を全部コピーして貼る
   - 上のフロッピーのアイコン(保存)を押す

3) スクリプト プロパティを入れる
   - 左の歯車「プロジェクトの設定」を開く
   - いちばん下の「スクリプト プロパティ」で「スクリプト プロパティを追加」を押し、次を入れる
       DRIVE_FOLDER_ID            Drive のフォルダ「Youtube日次」の ID
       LINE_CHANNEL_ACCESS_TOKEN  LINE のチャネル アクセス トークン
       LINE_USER_ID               LINE の送り先(自分)のユーザー ID
       LINE_SHARE_IDS             任意。カンマ区切り。レポートだけ一緒に送りたい相手の ID(知らせは送りません)
     値は、既存の「Youtube日次」プロジェクトの「プロジェクトの設定」->「スクリプト プロパティ」から写します
     (名前が違うときは、そのプロジェクトのコードを見て対応する値を探してください)
   - 「スクリプト プロパティを保存」を押す

4) 合言葉を作る
   - 上のツールバーの関数の選択欄(「関数を選択」)で makeSecret を選び、「実行」を押す
   - 初回は承認の画面が出る: 「権限を確認」->アカウントを選ぶ->「詳細」->「Youtube分析 連携(安全ではないページ)に移動」->「許可」
     (自分で作ったプロジェクトなので、この警告は出るものです。Drive・外部への通信・トリガーの許可を求められます)
   - 画面下の「実行ログ」に「合言葉(ツールの画面の「連携の設定」に貼る): ....」と出るので、その文字列を控える
     (もう一度 makeSecret を実行すると別の合言葉に変わります。変えたらツールの画面も直してください)

5) 設定を確かめる
   - checkSetup を選んで実行: 必須の 4 つが「あり」、「Drive のフォルダ: 開けました」、「raw フォルダ: あります」になっていれば OK
   - testLine を選んで実行: LINE に「Youtube分析 連携: LINE のテストです」が届けば OK
     (届かないときは実行ログの「LINE push 失敗 <番号>」を見ます。401 = トークンの間違い、400 = 送り先 ID の間違いが多いです)

6) ウェブアプリとしてデプロイする
   - 右上の「デプロイ」->「新しいデプロイ」
   - 「種類の選択」の歯車 ->「ウェブアプリ」
   - 説明: 好きな名前(例: 連携 v1)
   - 次のユーザーとして実行: 「自分」
   - アクセスできるユーザー: 「全員」(Google のログインなしで呼ぶため。合言葉が無いと何もできません)
   - 「デプロイ」を押し、出てきた「ウェブアプリ」の URL(https://script.google.com/macros/s/.../exec で終わるもの)を控える

7) 見張りのトリガーを作る
   - setupTriggers を選んで実行(1 時間ごとに watchdog が動くトリガーが 1 つできる。何度実行しても 1 つだけ)
   - 確かめるなら左の時計「トリガー」に watchdog がある

8) ツールに入れる
   - start.bat で入口を起動し、http://localhost:8700/analytics/ を開く
   - 「連携の設定」に、6) の URL と 4) の合言葉を入れて保存する(「接続を確かめる」で ping が通ればOK)

9) 既存の「Youtube日次」の自動実行を止める
   - 既存の「Youtube日次」のプロジェクトを開き、左の時計「トリガー」で pollAndSend のトリガーを削除する
     (残すと、12 時に「日次がない」と毎日届きます。見張りはこのプロジェクトの watchdog が代わりにやります)
   - ブックマークの受け取り(doPost)はそのまま使います。既存のプロジェクトとデプロイは消さないでください

■ 見張り(watchdog)が知らせること(日本時間)
  - 9 時台に今日の raw/<今日>.json が無い -> 「今日のデータがまだありません。iPhone の Safari で Studio を開いて、ブックマーク「日次取得」をタップしてください」
  - 13 時以降に今日の raw があるのに、PC から日報が届いていない -> 「今日のデータは届いていますが、PC で日報がまだ作られていません。PC と入口(start.bat)が動いているか確かめてください」
  - どちらも 1 日 1 回だけです。古い記録(120 日より前)は自動で消します

■ コードを直したとき
  - 保存したあと「デプロイ」->「デプロイを管理」->鉛筆(編集)->バージョン「新しいバージョン」->「デプロイ」
  - 「新しいデプロイ」を作ると URL が変わってしまうので、必ず今のデプロイを編集します

■ 操作の一覧(ツールが呼ぶ API。すべて POST、本文は JSON、合言葉 secret が要る)
  ping / list / get / report / status(詳しい形は Code.gs の先頭のコメント)
  失敗は {"ok": false, "error": "...", "message": "..."} で、HTTP の番号は 200 のままです
  error: secret(合言葉)・bad_request・bad_op・not_found・busy・line(LINE の失敗。レポートは保存済み)・internal

■ 注意
  - 合言葉と LINE の鍵は誰にも見せない・Git に入れない。ウェブアプリの URL だけでは何もできませんが、合言葉と一緒に漏れると raw のデータが読まれます
  - レポートの閲覧用 URL(?v=...)は、知っている人なら誰でも開けます(推測できない長さの鍵)。LINE の外に貼らないでください
  - 保存先: Drive の「Youtube日次」/reports/<日付>_<daily|weekly|monthly>.html(同じ日・同じ種類は上書き)
