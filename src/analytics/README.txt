==========================================================
  分析と日報  v0.1.1
==========================================================

チャンネルの数字から、日報・週報・月報を作って LINE に送ります。ホームの上の「分析と日報」(http://localhost:8700/analytics/)で、
状態の確認・手動の実行・報告の閲覧・連携の設定ができます。設計と決めたことは plan\analytics-daily-report.md。

■ 流れ
  1. iPhone の Safari で YouTube Studio を開き、ブックマーク「日次取得」をタップする(今までどおり)
     → 既存の Apps Script「Youtube日次」が Google Drive の Youtube日次\raw\<日付>.json に置く
  2. 入口(start.bat)が動いている間、数分ごとに Apps Script の「Youtube分析 連携」から新しいデータを受け取る
  3. 日報を作って連携へ送り返す → LINE に届く。同じ日にもう一度タップしたら、作り直して送り直す
  4. 週報は確定した週が変わったら、月報は確定した月が変わったら 1 回送る
  5. PC が止まっていた日は、起動したときに最新の分を送る。届かないときは Apps Script が LINE で知らせる(9 時台にデータが無い・13 時に日報が無い)
  画面の「取り込んで作り、LINE に送る」で、いつでも同じことを手で行えます(同じデータでも送り直す)。「送らずに作り直す」は画面で見るだけ。

■ はじめての設定
  src\analytics\gas\README.txt の手順で、Apps Script に「Youtube分析 連携」を作ってデプロイし、
  画面の「連携の設定」に URL と合言葉を入れます。既存の「Youtube日次」の pollAndSend のトリガーは消します(残すと 12 時に知らせが毎日届く)。
  画面では、予定の週のショートの本数(既定 28)と、境目の日(既定 2026-10-01。戦略が変わった日)も変えられます。

■ 報告の中身
  日報(LINE は短い要約・リンク先に詳しいページ)
    - YPP: 直近 90 日のショートの EV と 1,000 万(2027/2/1 から毎日判定)
      ① 必要な数の逆算(確率を使わない)・2/1 の見込み(本数ごと × 10/1 以降と前の 1 本あたりの強さ)・⑤ 当たりへの頼り方・
      ④ 感度の表・食い合いの推定・② 1 本あたりの強さの推移・⑥ 見込みの記録と答え合わせ・見込みの方法の答え合わせ・仮定の一覧
    - ショートの EV の日ごとのグラフ(確定と速報を分ける)・初動(公開からの経過時間で比べた順位)・いつもと違うところ・本数
    - 結果の指標と当たり率(視聴を継続・平均視聴率・再生 ÷ EV の帯ごと)
  週報: 週の合計(前週・4 週平均)・この週の動画・配信者別・長さ別・10/1 の前と後・中身の分析(直近 28 日)・YPP
  月報: 月の合計(前月)・週ごと・10/1 の前と後・効き目の表(要因ごとの差を大きい順に)・中身の分析(直近 90 日)・YPP

■ 数字の決まり(監査で見つかった前の仕組みの誤りを繰り返さないため)
  - 毎回その日のデータから計算し直す(固定のファイルを貼らない)。すべての数字に「いつタップしたデータか」「何日まで確定か」を書く
  - Studio の「日」は太平洋時間。本数は日本時間で数える。公開からの伸びは経過時間で数える(公開日の数時間ぶんを落とさない)
  - EV は取った日(太平洋時間)の 2 日前まで、収益は値の入った最後の日までを確定とする
  - 当たり・外れは固定の数字ではなく、直近 90 日の動画の中の順位で決める
  - 収益は Studio の値 ÷ 1000(単位は Studio の画面と見比べて確かめるまで要確認)

■ 作業データ(%LOCALAPPDATA%\youtube-tools\analytics\)
  config.json(連携の URL・合言葉・設定)・raw\(受け取ったデータ)・reports\(作った報告)・state.json(受け取り・送信・見込みの記録)
  合言葉とチャンネルの数字はリポジトリに入れません。

■ テスト
  py -3.10 -m unittest src/analytics/tests/test_analytics.py   (本物の数字は使わない。規則どおりに伸びる架空のチャンネルで確かめる)
