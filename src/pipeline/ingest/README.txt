録画の部品(recorder) — リアルタイム切り抜き(試験中)の録画
==========================================================================

配信中の YouTube を録画し、録画しながら見返せるようにする部品です(線 D の P1。計画: 資料の git:before-1028-cleanup:plan/line-d-live-clipping.md の 0)。
再生・マーク・書き出しの画面はスタジオの中です(P3)。書き出しはホームが行います。

■ 使い方
  1. ホームの「詳しく(サーバーの管理)」→「試験中の機能」で「リアルタイム切り抜き(試験中)」をオンにする(既定はオフ)
     → ホームが数秒〜30 秒のうちに、この部品を裏で起動します(黒い画面は出ません)
  2. スタジオの ② 解析の URL の欄に、配信中・配信前の YouTube の URL を入れる → 録画が始まり、③ 確認・書き出しでその録画が開きます
     配信の前でも始められます(始まると自動で録画します)。名前は配信の題が自動で付きます
  3. ③ のプレイヤーで、録画済みの所を再生・シークできます。「ライブ端へ」で最新へ
  4. 配信が終わると自動で「終了」になります。手で止めるときは、③ の LIVE の帯の「録画を止める」か、ヘッダーの「録画中」の札の「停止」
  5. マークと書き出し: いつものスタジオの操作でマーク → 「マークしたらすぐ書き出す」がオンなら自動で書き出し。
     終わりの時刻まで録画が届くのを待ってから、ホームが区間のセグメントだけをこの部品から取り、30fps に作り直して、
     スタジオの書き出し先(配信の名前のフォルダ)に置きます。
     区間に録画の欠け(繋ぎ直しの間)があるときは書き出さずに「要差し替え」と出ます(配信のあと、アーカイブから書き出します)
  6. 配信のあと: アーカイブが用意できたら、録画に無い区間(欠け・止めていた間)のマークだけをアーカイブから書き出します(自動。帯の「アーカイブから書き出す」でも)。
     録画から書き出した切り抜きはそのままです。アーカイブになったと確かめた録画は消します(下の「録画の置き場所」)

  オフの間は、画面にも出ず、この部品も起動しません。

■ 録画の置き場所
  既定は E:\Video\live-rec\ です。スタジオの設定(⚙)の「ライブの録画」で変えられます(録画中は変えられません)。
  ドライブが無いときは、作業データの中へ勝手に逃がさず、画面に案内を出して録画を始められないようにします。
  1時間あたり約 3〜4GB 使います。空きが 1GB を切ると録画を止めます。
  録画は自動で消します(設定の「アーカイブになったら録画を消す」でオフにできます)。
  消すときは、すぐには消さずに 置き場所の ごみ箱\<日付>\録画\ へ移します(3 日で消えます。それまでは戻せます):
    ・マークが全部書き出し済みで、YouTube のアーカイブで見られると確かめた録画 … すぐ
    ・アーカイブを確かめられない録画(メンバー限定・非公開など)… 終わって 3 日(2 日目から「調子」に予告)
    ・マークが 1 つも無い録画(試しに始めて止めた・見ただけ)… 終わって 24 時間
  採用のまま書き出していないマークがある録画は消しません。録画中・配信待ちの録画も消しません。
  空き容量はスタジオの設定の「ライブの録画」と、ホームの「調子」(オンのときだけ「録画元」の行)に出ます。

  <置き場所>\<録画の id>\recording.json          録画の記録
  <置き場所>\<録画の id>\session_001\index.m3u8   セグメントの一覧(HLS)
  <置き場所>\<録画の id>\session_001\seg_000000.ts 4 秒ごとのセグメント(配信をそのまま写したもの。作り直さない)
  切れて繋ぎ直すたびに session_002・003… が増えます。

■ 切れたとき・落ちたとき
  - 配信が切れたら 5 → 10 → 30 秒(以後 30 秒ごと)の間を空けて繋ぎ直します。10 分繋がらなければ「終了」にします
  - この部品が落ちた・PC を起動し直した: 次に起動したとき、書きかけのファイルを片付け、録画中だった物は新しいセッションで続けます
    (ホームがオンの間は 30 秒ごとに見回って、止まっていれば起こし直します)
  - ホームの「すべて終了」・黒い画面を閉じる・「起動し直す」では、録画は止まりません

■ ログインしたら自動で
  ホームを裏で起動するショートカット(src\app\start_hidden.vbs を shell:startup に置く。src\app\README.txt の「裏で動かす」)を使えば、
  ホームがこの部品も起こします(リアルタイム切り抜きがオンのときだけ)。

■ 入れる物
  streamlink(配信の取得)。setup\install.bat で入ります(setup\requirements.txt に版を固定)。ffmpeg も要ります。

■ 作業データ(リポジトリの外)
  %LOCALAPPDATA%\youtube-tools\recorder\  token.txt(合言葉)・settings.json(置き場所)・logs\recorder.log
  ホームから起動したときの黒い画面の出力: %LOCALAPPDATA%\youtube-tools\app\logs\recorder.log

■ API(一部)
  POST /live/<録画>/delete   録画を消す(録画中は消さない・置き場所の直下の録画のフォルダだけ。ホームが自動で消すのに使う)
  GET /live/<録画>/segments?start=&end=   区間の取得(区間にかかるセグメントと欠け・録画済みの最後の時刻。ホームの書き出しの「録画待ち」と「取得」が使う)
  名前を入れずに始めた録画には、配信の題を自動で付けます(YouTube の oEmbed。取れなければ題なしのまま録画は続く)。
  録画の画質の既定は 1080p です(ユーザー決定。4K の配信で容量が膨らむのを避ける。720p・いちばん良い(best)も選べる)。
  録画の記録(recording.json)の sessions が null・リストでないときは、起動時の復旧で落ちず、空として読みます。
