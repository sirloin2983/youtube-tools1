==========================================================
  YouTube 切り抜き・編集支援ツール  はじめに読んでください
==========================================================
このファイルが全体の使い方です(2026-09-26 に一本化)。各ツールの細かい使い方と変更の記録は、各フォルダの README.txt にあります。
AI(Claude・GPT)向けの決まりは AGENTS.md です。

【これは何?】
  配信から見どころを探して切り抜き、字幕を作り、DaVinci Resolve(以下 Resolve)で仕上げられる形にするまでを手伝うツールです。
  このパソコンの中だけで動き、動画・音声を外部のサービスへ送りません
  (YouTube からの動画・チャットの取得と、ランキング検索の YouTube Data API は使います)。

    入口(app)                          3つのツールをまとめて起動する。配信ごとの進み具合(案件)を見る・まとめて実行する
    ① 切り抜きスタジオ(clip-studio)    配信を探す → 解析して見どころの候補を出す → 確認して mp4 に書き出す
    ② 文字起こしツール(transcribe-tool)切り抜きの字幕を作って直す(faster-whisper。話者の判別も)
    ③ cut2resolve                      カットと字幕を、Resolve 用のパック(Text+ の字幕つき)にする

【準備(最初に1回)】
  1. Python 3(https://www.python.org/downloads/ 。Windows はインストール時に「Add python.exe to PATH」にチェック)
  2. ffmpeg     Windows: winget install Gyan.FFmpeg   / Mac: brew install ffmpeg
  3. yt-dlp     Windows: winget install yt-dlp.yt-dlp / Mac: brew install yt-dlp
     (入れたら黒い画面を開き直してください)
  4. 文字起こしの部品: transcribe-tool フォルダの install.bat をダブルクリック(Mac は install.command)
       話者の自動判別を使うなら install-diarize.bat も。NVIDIA の GPU がある人だけ install-gpu.bat
       (AMD Radeon・Intel の GPU では使えず、CPU で処理します)
  5. YouTube Data API のキー(ランキングの検索に使います。無くても解析・書き出しはできます):
       切り抜きスタジオの画面右上の「設定」で入れます

【起動と終了】
  起動: このフォルダの start-all.bat をダブルクリック(Mac は start-all.command)。
        黒い画面が1つ開き、ブラウザで入口の画面 http://localhost:8700/ が開きます。
        各ツールは入口と同じアドレスの /studio/・/transcribe/・/cut2resolve/ で動きます(入口のカードの「開く」)。
        ※ 127.0.0.1 ではなく localhost で開いてください(YouTube の埋め込みプレーヤーのため)
  終了: 入口の画面の「すべて終了」(誤操作を防ぐため2回押し)か、黒い画面を閉じる。
  ※ 2026-09-26 から、各ツールのフォルダの start.bat での単独起動はやめました。起動は start-all.bat だけです。
  ※ 新しいコードを取り込んだら(push.bat の後など)、「すべて終了」→ start-all.bat で起動し直してください。
    古いまま動いていると、画面の上に「版が違います」の赤い帯が出ます。

  窓で開く(試用・2026-09-26〜): 入口の画面の下の「窓で開く(試用)」をオンにすると、次に起動したときから、
    ブラウザのタブではなく Microsoft Edge の専用の窓(アドレス欄もタブも無い窓)で開きます。「いま窓で開く」ですぐ試せます。
    - 窓の中のリンク(「開く」「文字起こしで開く」など)も窓で開きます。YouTube などの外のサイトは、いつものブラウザで開きます
    - 窓の設定・拡張機能・ログインは、いつものブラウザと別です(専用のプロファイル: %LOCALAPPDATA%\youtube-tools\app\browser-profile)。
      そのため、会員限定・年齢制限のある配信は、窓の中の埋め込みプレーヤーで再生できないことがあります
    - 窓を閉じてもツールは止まりません。終わるときは今までどおり「すべて終了」
    - 合わなければスイッチをオフに戻すだけで、元のブラウザのタブに戻ります

【作業の流れ】
  1. 切り抜きスタジオ: ① 探す(配信ランキング)→ ② 解析(見どころの候補を自動で選ぶ)→ ③ 確認(マークを見て「採用」)→ 書き出す
       書き出すときに、切り抜きごとにバラバラな聞こえ方の音量(ラウドネス)を、既定で -14 LUFS(YouTube の目安)にそろえます。
       ③ の設定の「音量のそろえ方」で変えられます(「そろえない」なら以前と同じ音量 %)。
  2. 文字起こしツール: 書き出した切り抜きを開いて文字起こし → 画面で聞きながら直す(校正)
       直した字幕は、スタジオの ③ でも書き出したマークの下に「セリフ」として、元の配信の時刻で見られます。
  3. cut2resolve: 動画と文字起こしからパックを作る → パックの「友人へ.txt」の手順で Resolve に取り込む

  入口の画面の上の「案件(配信ごと)の一覧」では、配信1本ごとに、書き出した切り抜き・文字起こし(校正の進み具合)・パックの有無が並びます。
  作業中・投稿済み・見送りの「状態」と「メモ」も付けられます。

  「まとめて実行」(案件の一覧の各配信): 形を選んで押すと、残りの作業を順に自動で進めます。
    採用後を全部   … 採用したマークの書き出し → 文字起こし → パック(切り抜きの良し悪しは自分で決める)
    文字起こしまで … 書き出し → 文字起こし(パックは校正してから自分で作る)
    解析から全部   … 未解析なら解析 → 自動マークの点数の高いものを指定の数だけ採用 → 書き出し → 文字起こし → パック
  まだ無いものだけを作るので、途中で止めても、もう一度押せば続きから進みます。
  自動で作ったパックの字幕は校正前です。文字起こしで直したら、cut2resolve でパックを作り直してください。
  「解析から全部」の解析は、スタジオの ② 解析の「解析の設定」で保存した値を使います(設定はスタジオのサーバーに保存されます)。

  重い処理(解析・書き出し・文字起こし・パック作り)は、3つのツールを合わせて同時に2つまでです。
  3つ目からは「他のツールの処理が終わるのを待っています」と出て、順番に進みます。

【作業データの置き場所】
  文字起こし・マーク・設定・API キー・キャッシュ・ログは、このフォルダではなく
  %LOCALAPPDATA%\youtube-tools\(例 C:\Users\<名前>\AppData\Local\youtube-tools\)にあります。
  入口の画面の「作業データの置き場所」にパスが出ます(隠しフォルダなので、パスをコピーしてエクスプローラーに貼ります)。
  詳しくは docs\data-location.md。書き出した切り抜き・パックは、スタジオの設定の出力先と、動画の隣です。

【変更を GitHub に保存する(push.bat)】
  push.bat をダブルクリックすると、変更をまとめてコミットして GitHub に送ります。途中で次のことを自動で行います:
    - tools\removals.txt に書いてあるファイルを消す(AI が PC のファイルを消せないため。git の履歴には残ります)
    - これから送るファイルに、API キー・個人データ(文字起こし・data.json・設定など)・動画・大きすぎるファイルが混じっていないか調べ、
      あれば送らずに止まる(リポジトリは公開する方針のため)。止まったら、その表示を Claude に見せてください

【困ったとき】
  - 画面の上に赤い帯(版が違います): 入口の「すべて終了」→ start-all.bat
  - 動かない・エラー: 入口の画面の各カードの「ログ」、または %LOCALAPPDATA%\youtube-tools\app\logs\ の中の .log
  - 画面がおかしい・ボタンが効かない: 画面で起きたエラーは同じフォルダの client-errors.jsonl に自動で残ります(Claude に見せてください)
  - 表示や操作について: 各ツールの README.txt
