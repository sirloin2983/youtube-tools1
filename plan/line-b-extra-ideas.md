## 4. 決めたこと(ユーザー 2026-10-05)と、実装で守ること
- **A1: YouTube の自動字幕を取得してよい**(チャットの取得と同じ扱い = yt-dlp・公開の配信だけ・字幕だけ。こちらから動画・音声を送らない)。候補にだけ使い、正解・学習・辞書には使わない。評価用の文書には出さない
- 今すぐの 1〜5 を実装する。まとめ役(Fable 5.1)の意見として足した条件:
  1. 抜けの印は、10-05 の「空の行の下書き」(`ed_speakers.ovdraft_*`)を広げる(主の話者の声の区間に行が無い所を足す)。話者の判別の記録がある文書だけ
  2. 自動字幕が使えるのは、元の配信が分かる文書(文書の `clip` に配信の ID と時刻)だけ。配信に字幕が付いていないこともある → 先に手元の配信で付いている割合を数える。既定はオフ・当たり率を測ってから決める
  3. 読む速さの印は、字幕に出さない行(`noSub`)・空の下書きを外す
  4. 話者をならすのは行の話者だけ。守る行(`diar_keep_row` = 字幕に出さない行・「ゲーム音声など」・音のメモ overlap 付き・空の下書き)と、根拠の強い短い行(本物の相づち)は変えない。既定はオフ
  5. 時刻の配り直しは候補として出す(自動で書き換えない)。10-05 に行の終わりを調整したばかりなので、単語の時刻が人の直しに近いかを実測し、近くない端は候補にしない
