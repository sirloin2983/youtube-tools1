YouTube Studio 投稿時刻(Chrome 拡張) v0.1.0

■ できること
YouTube Studio(studio.youtube.com)のコンテンツ一覧(動画・ショート・ライブ配信)の「日付」の欄に、
公開した時刻を「2026/10/05 14:03」のように足します。欄の小さな文字が「アップロード日」の行は
アップロードした時刻です。時刻の上にマウスを置くと、秒までの公開・アップロードの日時が出ます。
時刻はその PC の時間帯(日本なら日本時間)です。

■ 安心のための説明
- 権限は何も求めません。studio.youtube.com の画面に時刻を書き足すだけです
- どこにも通信しません。Studio が自分の画面を出すために受け取っている一覧の情報(その中に時刻が入っています)を読んでいるだけです
- 見られるのは自分のチャンネルの情報だけです(Studio で見られるものと同じ)

■ 入れ方(Chrome。Edge なら edge://extensions で同じ手順)
1. 受け取った zip を展開して、消さない場所に置く(例: ドキュメントの中に yt-studio-time フォルダ)
   ※ 拡張はこのフォルダから読まれます。入れたあとにフォルダを消したり動かしたりすると外れます
2. Chrome のアドレス欄に chrome://extensions と入れて開く
3. 右上の「デベロッパー モード」をオン
4. 左上の「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダ(manifest.json が入っているフォルダ)を選ぶ
5. YouTube Studio のコンテンツの画面を開き直す(開いていたら再読み込み)
Chrome の更新のあとに拡張がオフになっていることがあります。そのときは chrome://extensions でオンに戻してください。

■ 更新(新しい zip を受け取ったとき)
展開して、同じフォルダの中身を置き換える → chrome://extensions でこの拡張の「更新」(丸い矢印)か、オフ → オン → Studio を再読み込み。

■ 外す
chrome://extensions でこの拡張の「削除」。そのあとフォルダは消してかまいません。

■ 出ないとき
- 一覧のページを再読み込みする。別のタブ(動画・ショート)に切り替えて戻す
- それでも出なければ、YouTube 側の作りが変わった可能性があります。作った人に知らせてください。
  F12 → Console に localStorage.yttStudioTimeDebug = '1' と入れて再読み込みし、[ytt-pub-time] で始まる行を送ると早く直せます

■ 作る側へ(このリポジトリ C:\dev\youtube-tools)
- 自分の Chrome には chrome-ext\yt-studio-time のフォルダをそのまま選べば入る(上の 2〜5)
- 友人に渡す zip は build.bat(node のテスト → dist\YtStudioTime.zip。中身は manifest.json・main.js・この README)
- 仕組み・テスト・直すときの注意は AGENTS.md。自動更新は無いので、直したら zip を作り直して渡す
